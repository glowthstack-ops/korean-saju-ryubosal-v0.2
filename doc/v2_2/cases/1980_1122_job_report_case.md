### 2-1. 金/木 역할 차이 — expert_review_required (이 케이스 하나로 엔진 변경 금지)

- **金(metal_role_mismatch)**: 상담사는 금을 '다재다능→목표 분산·커리어 관리 부담'(BAD)으로 해석,
  엔진은 한신. 단일 사례로 역할 분류를 바꾸지 않는다 — 감수 목록 등록만.
- **木(wood_role_ambiguity)**: 상담사 문서 자체가 ① 목 부재=문제(소속감·규칙 결핍, 건강 우려)와
  ② 목 유입=관성 압박(직업 변동·규칙 부담)을 혼용. **정적 결핍(원국에 없음)과 운에서의 작동
  (들어오면 부담)은 동시에 성립할 수 있다** — 용희기구한 단일 축으로 설명하려 하면 혼란.
  → 정적 vs 작동 분리 원리(`YONGSIN_OPERATIONAL_ROLE_SPEC.md`, operational 2계층)의 감수 사례로 활용.
- 기록 위치: fixture의 `review_flags[]` (status=`expert_review_required`). 테스트는 이 두 오행을
  **실패 기준으로 단언하지 않는다**(2026-07-03 데굴님 확정).

## 3. 상담 상품 구조 역공학

전달 구조: **서면 리포트 선(先) 발송 → 전화로 추가 설명 + 파생 질문 답변** 2단.

리포트(PDF) 목차:
1. 표지(브랜드 슬로건)
2. 기본해석 — 음양 개수 → 오행 분포(결핍 명시) → 일간 물상 → 일주 해석 →
   **핵심특징1 = 운의 흐름**(교운기·유리한 3년·투자/인복 창) → **핵심특징2 = 명의 흐름**(구조·적성·계절 대운)
3. 사주원국 해석 — 서사형 4항목(물상 스토리텔링) + **GOOD/BAD 오행 요약 박스**
4. 개운법 — 용신 오행별 '생활 행동 번역' 4항목(수→실버산업, 화·토→공부·차별대우·유료모임, 화→감사일기·햇빛 운동)
5. 대운의 흐름 — 현 대운 10년 성격 + 배우자/동업 궁합 권고
6. 건강 — 결핍 오행 기반 주의 부위
7. 궁금증 — 전화로 대체

전화(후속 Q&A) 유형: 리포트-실제 불일치 이의제기 2건("말이 매력적? 면접에서 말 못함"/"외로움? 못 느낌") /
취업·자금 회전 시기 / 사업 vs 직장 적성 / 투자·부동산 / 인맥 활용 경로(유료 모임) / 적합 직업 키워드 /
글쓰기·영업 재능 / "직감 믿어도 되나" 메타 질문 / "결혼 꼭 해야 하나" 규범 질문 / 유입 경로(통계).

## 5. 답변 방식 추출 → 반영 (P0~P2)

상담의 차별점은 판정이 아니라 **생활 언어 번역층**이다. 계산·판정 불변(원칙 1·12), 서술 지시·사전만 추가.

- **P0 — 서술 디렉티브 7종** (`saju_engines/structural_context.py`, 채팅·리포트 공용):
  1. `CONCLUSION_FIRST_DIRECTIVE` — 선택형 질문은 결론(권고 방향) 선제시 후 근거.
  2. `KEYWORD_COMBO_TRANSLATION_DIRECTIVE` — 용신·신살 신호를 활동 키워드 2~4개 조합으로 번역
     (직업명 단정 금지, 사전 밖 키워드 생성 금지).
  3. `NON_NORMATIVE_REASSURANCE_DIRECTIVE` — 결혼·직장 등 사회적 정답 강요 금지, 선택 자유 + 본인 기준 제시.
  4. `MANAGE_NOT_OVERCOME_DIRECTIVE` — 결핍·기신은 극복 대상이 아니라 관리 대상(노하우 동반).
  5. `DECISION_ATTITUDE_DIRECTIVE` — 운 품질 등급 → 의사결정 태도 번역(좋은 시기=직감 실행,
     불안정 시기=점검·내실). 등급은 엔진 판정만 근거.
  6. `AVOID_DATE_CERTAINTY_DIRECTIVE` — 특정 달 단정 금지, activation window·'점검할 만한 창'으로.
  7. `TRAIT_FEEDBACK_DIRECTIVE` — 성향 반박 수용: 실제 경험 우선 → 정적 잠재 vs 작동 조건 재해석 →
     확인 질문(상담사가 회피했던 지점을 우리가 더 잘하는 영역으로).
- **P1 — 활동 키워드 번역 사전**: `backend/dictionaries/interpretations/activity_keyword_map.json`
  (오행 5종 + 현침살, 전 항목 reviewed:false). **직업 추천 사전이 아니라 활동 키워드 번역 사전** —
  직업 단정 리스크 없이 상담사식 구체성 확보.
- **P2 — 개운 행동 사전**: `backend/dictionaries/interpretations/remedy_action_map.json`
  (원칙 3종: not_magic/behavior_first/avoid_certainty + 오행 5종 행동, reviewed:false).
  기존 `remedy.json`(D-3 6분기)과 별개 축 — 상황 분기가 아닌 **오행 보완 행동** 사전.
- **배선**: J-07에 활동 키워드+개운 행동 블록 부착(용신·희신=살릴 기운, 기신·구신=기준 세울 기운,
  원국 신살 매칭). J-06 가이드에 시기 단정 금지 강화. 행동 전략 섹션군에 관리·태도 디렉티브,
  R-07/RP-09에 탈규범 디렉티브. 채팅은 질문 유형별 트리거(비교/개운/장기흐름/성향반박/규범).

## 6. 모방 금지 포인트

- **시기 단정**: 상담사의 "빠르면 8월, 10월경 특히 좋다"는 우리 원칙 3·4 위반 —
  "움직임이 강해지는 달 / 제안·면접·자금 흐름을 점검할 만한 창"으로 번역한다(Trigger≠Execution).
- **승부·결과 단정**: "취업된다" 류 확정 표현 금지(원칙 8) — 가능성·기류·준비 전략으로.
- **불일치 이의제기 회피**: 상담사는 사용자의 성향 반박에 설명을 이어가기만 했다 — 우리는
  `TRAIT_FEEDBACK_DIRECTIVE`로 수용·재해석·확인 질문을 명시 규칙화한다.
