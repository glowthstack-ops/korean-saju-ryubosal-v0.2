# 관계 궁합 개선 (Relationship Reading Enhancement) — v1

> 전문가 영상("관계 사주로 보는 법") + 사용자 2차 리뷰(2026-07-01) 기반. 기존 궁합의 안정축·
> 끌림축에 더해 **관계질 라벨 · 궁위 관계망 · 12신살 상대위치 · 삼합국 관계 역학**을 보강한다.
> 본 문서는 **초안(reviewed:false)**. 승패·서열·성별 위계·정신질환 단정은 금지하며, 리스크가 큰
> 항목(삼합국 역학)은 **shadow/설명 보조 레이어 우선**으로 도입한다.

## 0. 핵심 원칙

- **관계는 서열·승패가 아니다.** "이긴다/못 이긴다/우열"로 표현하지 않고 **주도·수용·보완·부담·
  경쟁 등 관계 역학의 보조 신호**로만 서술한다(원칙 3·8).
- **단독 단정 금지.** 라벨 하나로 관계를 확정하지 않고 대운·세운·궁위 합충형파해·용신기신·질문
  맥락과 함께 본다.
- **성별 위계·정신질환 해석은 초기 릴리즈 제외**(§보류). 필요 시 성 중립 역할·컨디션 문구로만.

## 2. P4 — 관계질 라벨 사전 (1순위, 低리스크)

합·충·형·파·해·원진·공망을 관계 해석용 **중립 문구**로 표준화한다. LLM 답변 품질을 크게
안정화하므로 **가장 먼저** 한다. 낙인·자극 표현은 `avoid_phrases`로 차단.

| 관계 | 라벨 | 중립 요약 | avoid |
|---|---|---|---|
| 합(合) | connection | 연결·협력·끌림 (합거/합반이면 묶임·지연 가능) | — |
| 충(沖) | volatility | 충돌·변동·분리·이동 (깔끔한 독립은 조건부) | — |
| 형(刑) | adjustment | 조정·압박·교정·소모 (직업화 가능) | — |
| 파(破) | fracture | 균열·약속 깨짐·관계 지속성 약화 | — |
| 해(害) | erosion | 은근한 방해·오해·서운함·누수 | — |
| 원진(怨嗔) | binding_conflict | 끌림과 불편함이 함께 생기는 감정 소모형 관계 | `악연`,`속궁합`,`절대 못 헤어짐` |
| 공망(空亡) | hollow | 실체감 부족·거리감·기대와 현실의 간극 | — |

각 항목은 `{relation_type, relationship_label, tone, summary, avoid_phrases[]}` 스키마로 사전화한다
(직접 작문 금지, 템플릿 치환). **해(害)는 기존 서술에서 누락돼 있으니 반드시 포함.**

## 3. P3 — 궁위 관계망 통독 (2순위, 低리스크)

배우자궁 중심을 넘어 **연·월·일·시 궁위 관계망**을 종합한다.

**궁위 영역**: 연주=조상·가문·사회 배경·국가/공적 / 월주=부모·형제·성장환경·사회 기반 /
일지=배우자·친밀관계·생활 중심 / 시주=자식·후대·말년·결과물.

**궁위 간 관계**: §2 관계질 라벨(합/충/형/파/해/원진/공망)을 궁위 쌍에 적용해 서술.

**cross-palace는 조건부(질문 intent가 맞을 때만)**:
- 월주–시주 삼합: 가족–자식 영역 연결 가능 → 질문이 육아·돌봄이면 "조부모 육아로 발현 가능",
  사업·성과물이면 "가족 기반 도움으로 발현 가능"으로 **조건부** 노출.
- 연주 삼합 완성: 공적·사회 영역 인연 → 질문이 공공사업·입찰이면 조건부 언급.
- "항상 그렇다"로 일반화 금지 — intent allowlist로 게이트.

**구현 상태(v1, 2026-07-01)**: `palace_relationship_network.py`(engine `analyze_palace_network` +
renderer `palace_network_lines`) + `shared_types/palace_network.py`. chat·report의 **관계·자산
섹션(relationship/general)** 에 배선. 궁위 쌍 관계(육합·반합·충·형·파·해·원진)와 궁위 공망을
P4 라벨로 렌더하며 점수 미개입. cross-palace 발현은 **가족(월-시/연-시 합)만 relationship/general
조건부**로 v1에 포함. **연주 공공·입찰 발현(career/wealth)은 v2로 지연**(과노출 방지).

## 4. P2 — 12신살 상대위치법 (3순위, 신규 계산기, explanation-first)

나의 지지 기준 상대 지지가 어느 12신살에 놓이는지 계산한다. **점수화 전에 설명 태그부터**.

**신규 함수**: `get_relative_sinsal(base_branch, target_branch) -> RelativeSinsalResult`
```
{ base_branch, target_branch, sinsal, category, relationship_reading, confidence }
```

**기준점 분리 필수**(하나로 합치지 않는다):
- `year_branch_relative`: 사회적 관계·세대감·외부에서 보이는 분위기 (년지 기준)
- `day_branch_relative`: 친밀 관계·배우자궁·실제 동거/연애/결혼 체감 (일지 기준)
- `palace_relative`: 부모궁·배우자궁·자식궁 등 궁위별 보조

**서비스 기준점 우선순위**:
- 궁합/연애/결혼 → **일지 기준 우선 + 년지 보조**
- 부모자식/상하 → 년지·월지·시지 병행
- 사회·조직 → 년지·월주 중심

**비대칭 필수**: `A 기준 B`와 `B 기준 A`를 **둘 다** 계산한다(예: A→B=천살, B→A=반안살 — 서로
체감이 다르며, 이 비대칭이 궁합 설명력을 높인다).

**해석 가드**:
- 천살·육해·망신(상대가 크게·부담) / 겁살·연살·반안(편함·만만)은 **역학 경향**으로만, 승패 금지.
- 연살/도화 계열은 **매력·표현성·호감 유발·감정 끌림**으로. **"소비 성향"은 단독 금지** — 재성/
  식상 활성·도화 과다·운의 재성 활성과 **함께일 때만** 보조적으로 언급.

## 5. P1 — 삼합국 기반 관계 역학 (4순위, shadow-first, 中리스크)

亥卯未=木 · 寅午戌=火 · 巳酉丑=金 · 申子辰=水 삼합국을 기준으로 두 사람의 에너지 결을 비교한다.
**"위/아래·승패·서열"이 아니라 오행 생극으로** 정리한다(엔진화·상용화에 안정적).

| 두 삼합국 오행 관계 | 라벨 | 관계 역학(경향) |
|---|---|---|
| 같은 국 | 편안(comfort) | 결이 비슷해 익숙·편안 |
| 내가 상대를 生 | 지원(support) | 내가 에너지를 써주거나 돕는 결 |
| 상대가 나를 生 | 끌림/받음(nourished) | 상대에게 기대고 받는 결 |
| 내가 상대를 克 | 주도(lead) | 내가 규칙·방향을 쥐는 결 |
| 상대가 나를 克 | 부담/긴장(pressure) | 상대가 압박·규칙·긴장으로 느껴질 수 있음 |

예: 내 국=木, 상대=金 → 金克木 → 상대가 압박·긴장으로 느껴질 수 있음(단정 아님). 내 국=木,
상대=火 → 木生火 → 내가 상대를 돕는 결.

**도입 방식**: **shadow 계산 + LLM 보조 설명**으로 먼저 둔다(안정/끌림축 점수에 미반영). 검증 후
승급. 승패·서열 표현은 어떤 형태로도 금지, 소송 우열은 원칙 8 준수.

## 6. 보류 (초기 릴리즈 제외)

- **F. 음양 성별 역학**("남양·여음", "여자가 위면 남편이 못 이김"): 성별 고정관념 리스크 → 제외.
  도입 시 성별과 분리해 `lead_role/support_role`·`active/receptive`·`expressive/stabilizing`처럼
  **관계 내 역할**로만.
- **G. 수화 정신영역 + 탕화살**(우울·조울·ADHD·분노): 의료·낙인 리스크 매우 큼 → 제외. 향후에도
  질환명 금지, "수면·감정 기복·예민·과로 누적 조심"(수화)·"감정 반응이 빠르게 올라올 수 있는
  시기"(탕화살)처럼 **컨디션 문구로만**, 전문의 상담 권장 톤.

## 7. 진술축미 환절기(보조 신호)
辰戌丑未는 계절 전환 기운이 강한 지지 → 관계·생활 기반에서 정리·전환·재배치가 일어나기 쉽다.
특히 원국에 파·충·형이 있고 운에서 다시 건드리면 관계 안정감이 흔들릴 수 있다(보조·비단정).

## 8. 우선순위 & 결정 로그 (2026-07-01 사용자 승인)
```
1차 P4 관계질 라벨 사전(해 포함·중립화)
2차 P3 궁위 관계망(cross-palace는 intent 조건부)
3차 P2 12신살 상대위치법(신규 계산기·년지/일지 분리·양방향·explanation-first)
4차 P1 삼합국 관계 역학(오행 생극·shadow-first, 승패/서열 금지)
보류 F 성별 위계, G 정신건강/탕화살
```
1. P1은 "위계/승패" 아닌 오행 생극 역학으로 재프레임 + shadow-first.
2. 12신살 상대위치는 **신규 계산기**(현황 과대평가 정정). 년지=사회·일지=친밀 분리, 양방향 비대칭.
3. 원진≠속궁합, 연살≠소비(단독), 해(害) 추가.
4. 성별·정신건강은 초기 제외.
