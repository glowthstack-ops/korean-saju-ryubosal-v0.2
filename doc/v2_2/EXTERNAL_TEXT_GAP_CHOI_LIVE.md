## 2. 왜 인기 있는가(스크립트 관찰)

1. **조건을 건너뛰고 "그래서 어떤 사람인데"로 직행한다.** 발생 조건은 한 줄로 넘기고, 지장간 설명을 시작하자
   시청자가 빠져나가는 것을 진행자가 직접 말한다.
2. **길흉어 대신 생활 장면으로 말한다.** 암록 = 서프라이즈 파티를 싫어함, 인성 다자 = 얹어 준 반찬을 일단 고맙게
   받음, 관성 강한 아이 = 어느 학교에 가도 비슷한 등수. 듣는 사람이 자기 일로 바로 확인한다.
3. **원리를 한 줄로 붙인다.** 신비화하지 않고 "왜 그런지"를 한 문장으로 준다.
4. **흉을 성향으로 번역하고 있다/없다를 거부한다.** 충 = 두 기질이 번갈아 나옴(능력이 두 개), 공망 = 간절한데
   만족이 안 돼 계속 움직이는 힘. "사주는 온오프가 아니라 강약".
5. **대비 구도.** 같은 상황(주말 워크숍 공지)에 편관·무관·상관이 각각 어떻게 반응하는지, 인성 다자와 무인성,
   신강과 신약을 나란히 놓는다. 주변 사람이 떠올라 공유로 이어진다.
6. **처방이 행동 단위.** 식상 = 가르치면서 공부, 재성 아이 = 보상을 걸기, 관성 아이 = 그룹을 올려 주기.
7. **약점과 강점을 한 쌍으로, 놀리되 편을 든다.** "부족함이 발전을 가져온다"가 반복되고, 일간 10개를 한 이야기의
   배역으로 나눠 우열 없이 모두에게 역할을 준다.

## 5. 데굴님 결정(2026-11-28)

0. **건강·신체·외모 소재** — "약간의 재미 형태의 놀림 멘트로 활용 가능". 판정·조언 문장으로는 계속 쓰지 않고,
   사전의 놀림 칸(`tease`)에만 둔다. 진단명(주의력·수면·기분 관련 병명 등)은 놀림에도 쓰지 않고 "잠이 보약인 쪽"
   같은 일상어로만 쓴다(같은 날 데굴님 확인 "그래") — lint 로 강제.
1. **시작 범위** — P0 대조 문서 → P1 귀인 4종까지를 첫 묶음으로.
2. **황은대사** — 대조 후 이번 범위에 포함(§4).
3. **용신운·기신운 체감** — 낱말로 대조하지 말고 원인과 결과로 잇는다. "정체되어 있으니 움직일 방향을 찾지 못해
   몸이 편하고, 몸이 움직이지 않으니 더 필요한 자원이 들어오지 않고, 그로 인해 기존에 쌓아 둔 것으로 소모하니
   부담스럽게 된다." → 기신운 = 정체 → 당장은 편함 → 유입 없음 → 축적분 소모 → 부담. 용신운 = 움직이도록 떠밀려
   힘들게 느껴질 수 있음 → 그 움직임으로 필요한 자원이 들어옴(발판). 판정(용신=발판·기신=소모)은 그대로이고
   체감 문장만 이 흐름으로 쓴다.
4. **놀림·유머** — 반드시 필요. 놀림 소재(내용)는 사전에, 말투는 페르소나에 둔다.
5. **유입 콘텐츠** — 이번 진행 건에서 제외, 다음에 고려.
