# 해외 근무(주재원·파견·해외 취업·이민) 질문 층 — 설계 SSOT

> 2026-10-28 데굴님 승인("제안대로 진행하자", 참고 체계 제공). 구현: `backend/packages/saju_engines/saju_engines/overseas_work.py`,
> 파서 배선 `query_parser.parse_message`, 채팅 배선 `chat_service`(말미 블록). 회귀: `tests/unit/test_job_change_overseas_explain_20261028.py`.

## 1. 배경

실로그 web-mvrq8ocg: "내가 주재원을 나가고 싶은데 해외에서 일한 운이 몇년도에 있어?"가 파서에 해외 근무 어휘가 없어
career 총운(12개월)으로 떨어졌고, 임베딩 보강이 `career_change`를 채워 답이 국내 이직 제안·면접·스카우트 시기 서술이 됐다.
사용자가 "아니 난 이직을 했다니까!"로 되받았지만 또 이직을 전망했다(docs/03 B7 이직 완료 사실 교정과 짝).

## 2. 참고 체계의 원칙 → 본 리포 번역

데굴님이 제공한 참고 체계(전통 명리의 역마·관성·인성·재성 해석을 현대 해외 근무에 적용한 추론 틀)를 다음처럼 옮겼다.
고전에 해외 주재원이라는 분류는 없으므로 **해석 틀**이지 검증된 예측 모델이 아니다 — 블록과 지시에 그대로 적는다.

| 참고 체계 | 본 리포 구현 |
|---|---|
| 역마=이동 후보, 해외 출국 확정 아님 | 이동 신호 = `relocation` 후보 최고 점수(연 단위 묶음). 등급은 직업 신호와의 **동시 활성화**로만 정한다 |
| 관성=조직·직위, 인성=제도·문서, 재성=경제, 식상=실무 수행 | 세운 기둥(천간·지지 십성)의 십성 군 → **서술 힌트**(관성 주도=조직 발령형 검토 등). 판정 아님 |
| 유형 A 주재원·발령 / B 파견·출장 / C 해외 취업 / D 이민 | `detect_overseas_work` 5유형(assignment/dispatch/local_hire/emigration/unspecified). 유형별 직업 키: A=승진·계약문서·이직, B=계약문서·이직, C=이직·취업·계약문서, D=계약문서·이직 |
| 원국·운 분리, 시점은 대운·세운 동시 활성화 | 연도별 표: 이동 점수 × 직업 점수 → 강(둘 다 ≥55)/중(둘 다 ≥40)/이동만/직업만/없음. 점수 눈금은 `tone_for_score`의 '약함' 상한(55)과 같다 |
| 사건 확정도 부족 시 완화 표현 | 지시 ②: '강'이어도 "직장과 거주 환경이 함께 바뀔 가능성"으로. 이동만/직업만은 국내 이사·국내 직무 변화와 구분 불가라고 밝힘 |
| 단계: 제안→발령·계약→출국→현지 근무→연장·귀국 | 지시 ④ |
| 발생 가능성 ≠ 성과, 용신 오행만으로 성과 판정 금지 | 지시 ⑤: 용신 정렬은 '기반'으로만 |
| 단일 신살·십성 과대평가 금지 | 지시 ① |

**새 점수 모델은 없다.** 기존 사건 후보 점수와 세운 십성을 조합·표기만 한다(절대원칙 1·9·10). 역마(상대 12신살) 자체는
`movement_timing_shadow`가 로그 전용으로 다루며 이 층은 쓰지 않는다 — 승격은 별도 측정 후.

## 3. 파서 배선

- 어휘(유형 순): 주재원·주재 근무/발령·해외 발령/전근/근무지/지사 → assignment; 해외 파견/출장·파견 → dispatch; 해외 취업/이직/채용·현지 채용·외국(계)/글로벌 회사로 이직 → local_hire; 이민·해외 정착/이주·영주권 → emigration; 해외 근무/생활/진출/일자리·해외에서 일/근무·해외로 나가·외국에서 일 → unspecified.
- '해외 여행'처럼 여행·관광만 있으면 비적용(기존 이동 사건 경로).
- 의도: `overseas_work` 필드, 도메인 직업(이민=이동), `event_key=relocation`, `event_keys=유형별 직업 키`(사용자가 '취업·이직'을 명시했으면 그 키를 앞에). 이직을 주 사건으로 두면 국내 이직 서술·진입 두 칸 지시가 따라오므로 금지.
- 후속 턴(시점 교체·'그 이후 5년')에 `overseas_work`를 승계한다.

## 4. 채팅 배선

- 연도 창: 질문의 절대 연 창 > 지평 years_span > 올해부터 5년.
- 후보 풀: 도메인 필터 **전**(`all_scored`+확장 연 후보) — 이동 후보는 직업 도메인 필터에서 빠지기 때문. 세운 기둥은 기본 창과 확장 창을 합친다(2032~2036 같은 원거리 창도 표가 나온다).
- 출력: `[해외 근무 신호 — …(유형)]` 헤더 + 연도 줄(`- 2027년 丁未 — 이동 64 · 직업 87(계약·문서) → 직장·거주 환경 동시 변화 가능성 — 강 · 용신운 · 힌트: …`) + `[해외 근무 해석 규칙]` 6조. 로그 `overseas_work kind= years= tiers=`.
- '몇 년도' 질문은 docs/03 B7 year_when 지평(향후 5년·진입 두 칸 없음)과 결합된다.

## 5. 보류·후속

- 역마 성립(상대 12신살)·충 촉발을 이동 신호에 합산하는 것은 측정(오탐·동시상승) 후 결정 — `movement_timing_shadow` 메모 참조.
- 유형 힌트 어휘·블록 밀도는 실답 감수 후 조정(검수는 실사용 답변으로).
- 리포트(총운/집중) 섹션 노출은 미배선 — 채팅 전용.
