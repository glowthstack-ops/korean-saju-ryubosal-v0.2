# 외부 강의 대조 — 「길흉은 혼자 오지 않는다」 vs 류보살 v2 엔진 (2026-10-29)

> 같은 강사의 대운 강의와 짝. 엔진에는 교운기 체감 신호 지시·재물 준비기 층이 있지만 **교운의 방향(맞는 대운↔맞지 않는 대운)에 따른 조언**이 없었다.

## 1. 대조

| 강의 | 엔진 | 처리 |
|---|---|---|
| 명 불변·운 변화, 인연은 예측 어려움 | 대운 풀이 관점 | 동등 |
| 너 자신을 알라 | 자기인식 지시 | 동등 |
| 하인리히 법칙 — 운이 바뀌기 전 작은 징조가 잦아짐 | 교체기 체감 신호 지시 | 징조 구절 추가 |
| 나쁜 대운→좋은 대운 직전: 꽃샘추위 같은 마지막 고비, 길지 않음, 준비 | 없음 | 교운 방향 문구 `bad_to_good` |
| 좋은 대운→나쁜 대운 직전: 오히려 일이 더 잘 풀림(거래처·투자자) → 무리한 확장·대출 투자 → 나락, 전문가·주변·배우자 상의·감당 가능선 | 없음 | 교운 방향 문구 `good_to_bad` |
| 불행은 행운의 가면, 행운은 불행의 가면 — 잘 나갈 때 한 걸음 늦추기 | 없음 | 위 문구에 포함 |

## 2. 데굴님 결정 (2026-10-29)

1. 서술층 진행. 2. 범위는 "교운기 = 대운 기준 앞뒤 1년(2년), 길면 앞뒤 2년(4년)" — **엔진 기준**으로: 교운 가중(교운일 기준 라플라스형, 스케일 365일) e^-1 이상 = 앞뒤 1년 핵심, e^-2 이상 = 앞뒤 2년 여파. 3. 혼합·평운·트리거운은 방향 판정 제외.
