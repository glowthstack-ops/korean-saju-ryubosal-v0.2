# 외부 강의 대조 — 재물 3편(「어떤 운에 돈을 버는가」·「재물 그릇의 크기」·「재물 그릇이 큰 것만 좋은가」) vs 류보살 v2 엔진 (2026-10-29)

> 같은 강사의 이직·이별운·남녀 차이 강의와 짝. 강의는 참고 문헌이며, 점수 규칙은 85사례·원장 적중률로 ON/OFF, 서술층은 ON 후 실답 감수. 재물 사건은 가능성형, 수익·당첨 확정 금지, 경고 반복 금지(원칙 8).

## 1. 강의 요지

- **돈 버는 시기**: 일간·식상(행위)·재성(돈)·겁재(빼앗는 자). 원국 식상만 있으면 운에서 재성이 올 때 벌 환경이 열리고, 원국 재성만 있으면 운에서 식상이 올 때 뜻을 펼친다. 둘 다 없으면 인성(머리)·관성(안정 소득) 경로. 원국 재성 + 운 겁재는 관성이 없을수록 위험, 정관이 나타나면 겁재가 물러선다. 신강하면 겁재가 조심스럽게, 신약하면 적극적으로(도와주는 척 지분 요구) 다가온다. 편재가 정재보다 규모가 크다. 원국 재성 + 운 겁재 / 원국 겁재 + 운 재성 — 달콤한 제안에 눈·귀 반쯤만.
- **재물 그릇의 크기**: 그릇 = 일간 강약 × 재성 강약(재성은 식상의 생을 받고 극을 받지 않아야 튼튼). 월지·일지의 인성·비겁이 신강 조건. 신왕재왕(가장 큼)·신왕재약·신약재왕(운 인성·비겁이 오면 취함)·신약재약(가장 작음). 그릇은 조건일 뿐 실제 재물은 운과 노력. 원국 재성 + 운 식상 = 앞마당 석유를 캐냄, 원국 식상 + 운 재성 = 밖에 나가 벌어옴. 옛날엔 여성 신강을 나쁘게 봤지만 지금은 남녀 모두 튼튼해야 한다.
- **그릇이 큰 것만 좋은가**: 그릇 크기 × 운에서 오는 재물 양 → 만족도. 그릇 큼 + 유입 적음 = 결핍감(늘 돈돈), 그릇 작음 + 유입 많음 = 과욕·재극인(관계·건강 훼손, 나눔으로 완화), 작음 + 적음 = 비교에서 오는 빈곤감, 적당 + 적당 = 이상적. 재물은 불행을 막는 조건이지 행복의 절대 조건은 아니다.

## 2. 대조표 (코드 사실, 2026-10-29)

| 강의 | 엔진 | 판정 |
|---|---|---|
| 원국 식상만 + 운 재성 / 원국 재성만 + 운 식상 | 운 적용 구조 층(`pattern_transit`)이 식상생재 '신규 성립'으로 잡음(원국 한쪽 10%+ + 운 보충) — 문구는 일반형. 점수 쪽 횡재 발동 식상생재는 운 천간에 식상·재성 동시 투간일 때만. | 서술 보강 + 점수 측정 |
| 식상·재성 부재 → 인성·관성 경로 | 부/귀 지향 블록(관인 → 귀)만. | 서술 보강 |
| 원국 재성 + 운 겁재, 관성 있으면 물러섬 | `JIECAI_RESTRAINED_BY_OFFICER`(관살 있으면 겁재 손재 완화). | 동등 |
| 신약일 때 겁재 지분 요구 | 신약 명식은 비겁 용신이 많아 좋은 품질로만 읽힘. | 서술 보강 |
| 재성×겁재 달콤한 제안 경계 | 비겁+재성 조합은 운 스택 안에서만, 사기형 위험은 단일 신호 적격 금지. | 서술 보강 |

## 3. 데굴님 결정 (2026-10-29) — "권유대로 진행할게, 4번도 진행해"

1. 재성 튼튼 = 기존 결혼 자원 블록의 재성 세력 강(비중 22%+ 또는 3자리+) **그리고** 식상 10%+. 신강약은 엔진 판정(`wealth_capacity._is_strong` — 강신 게이트 또는 '강' 밴드).
2. 시기 재물 유입 = 그 기간 재물 후보(재물 변화·횡재) 최고점 ≥70 '많음', <55 '적음'(사건 후보 55·'가능성 높음' 70 문턱 재사용).
3. 노출 = 채팅 재물 질문 + 리포트 재물 섹션.
4. 점수층(원국 한쪽 + 운 한쪽 식상생재 횡재 발동) 측정 진행.
