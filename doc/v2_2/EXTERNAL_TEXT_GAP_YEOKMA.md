# 외부 강의 대조 — 「역마살」 vs 류보살 v2 엔진 (2026-10-29)

> 같은 강사의 재물·대운·식상생재 강의와 짝. 핵심 정의가 2026-10-06 엔진 정의 통일(`MOVEMENT_TIMING_SHADOW.md`)과 충돌해, 정의는 유지하고 글자별 결·조언만 서술층으로 반영한다.

## 1. 정의 충돌

- 강의: 지지에 寅申巳亥가 있으면 역마살.
- 엔진(2026-10-06 데굴님 확정): 寅申巳亥 보유 = '이동지' 표지(LLM 비노출 설계), 역마살 = 연지·일지 삼합국 기준 상대 12신살, 실제 이동 = 충·식상 등 동반 신호.
- 결정(2026-10-29): **엔진 정의 유지**. 강의 정의를 따르면 대부분의 명식이 역마살을 갖게 되고 '근거 없이 떠돈다' 문장 금지가 무너진다.

## 2. 대조

| 강의 | 엔진 | 판정 |
|---|---|---|
| 寅申巳亥 보유 = 역마살 | 이동지 표지와 역마살 분리 | 충돌 → 엔진 유지 |
| 생지=계절의 시작, 왕성한 에너지 | 이동지 해설 '시작·출발의 추진력' | 동등 |
| 양면성(불안정 vs 맹렬한 의욕) | 역마살 해설 단점·장점 | 동등 |
| 寅·申·巳·亥 글자별 결 | 지지 물상 키워드만, 역마 해설에 글자별 결 없음 | 서술 보강 |
| 시작 전 숙고·조언·리스크 점검·주변 사람 배려 | 주의 문구는 '피로·일정·이동 안전'뿐이고, 주의(caution) 필드는 프롬프트에 렌더되지 않음 | 서술 보강(새 필드) |

## 3. 구현

- `sinsal_text.json` 역마살에 `byBranch`(寅·申·巳·亥 4칸)·`advice` 신설, `SinsalTextItem.by_branch`/`advice`(선택). 이동지에는 두지 않는다.
- `chart_interpretation._sinsal_branch_advice_note`: 원국 신살 발췌(성립 자리의 지지 글자)와 운 신살 줄(운 지지)에 '글자별 결 … 조언 …' 꼬리.
- 원국 신살 발췌에서 역마살이 있으면 이동지 표지를 후보에서 뺀다 — 표지가 5개 슬롯을 먼저 차지해 성립한 역마가 밀리던 결함(예: 1984-01-12 남).
- 점수·판정 불변. 테스트 `test_yeokma_lecture_20261029.py` 5건.

## 4. 후속 조사·교정 (2026-10-29, 데굴님 "이 부분에 대한 조사를 진행하고 관련 작업을 진행해")

**조사 결과**
- 원국 신살 발췌(`build_chart_interpretation` → `_sinsal_excerpts`)는 **고정 prefix 콘텐츠**라 질문과 무관하게 같아야 한다(캐시). 선택 순서는 주요 길신 → 주요 주의 → 일주 신살, 상한 5개. 역마살은 중립이라 주요 목록에 없고 일주에 있을 때만 후보 — 표본 96명식에서 성립 58건(시주 43·연주 9·일주 6) 중 발췌 노출 0건(이동지 슬롯 교정 전 측정 — 교정 후에는 일주 역마 일부만 노출). 발췌 순서를 질문별로 바꾸면 고정 prefix 가 깨지므로 발췌는 그대로 둔다.
- 운 신살 줄은 `build_luck_grounding`(연·월·일 총운 경로)에만 있다. 이사·이직 질문은 사건 후보 경로로 답하고, 이사 질문은 이사 전용 블록으로 답해 사건 후보가 0건인 경우도 있다(실측: '2028년에 이사나 이동 운' → 후보 0). 후보는 대개 월 단위라 세운 지지로 들어오는 역마(2028 戊申)도 빠졌다.

**교정(서술층, 점수 불변)**
- `chart_interpretation.yeokma_natal_lines`: 원국 역마 성립 자리(지지 글자 포함)·의미·위치별(사회/개인)·글자별 결·조언 1블록 — 채팅 **이사·직업 질문** 구조 블록에만(재물 등 다른 질문 제외).
- `chart_interpretation.yeokma_period_lines`: 후보 기간 + 질문 시점 범위 연도 중 운 기둥 `luck_sinsal` 에 역마가 있는 기간을 fromLuck·글자별 결로 나열, 월 후보는 그 해 세운도 함께 본다, 상한 6줄, 조언은 블록 끝 1회 — 채팅 **이사·직업 질문** 말미에.
- 실측: 1984-01-12 남 이사 질문 → '위치: 연주(亥), 일주(巳), 시주(巳)' 블록, 재물 질문엔 없음. 1970-10-12 남 '2028년 이사' → '2028 戊申 … 申 역마', '2027년 이직'(역마 없음) → 블록 없음.
- 테스트 3건 추가(총 8건).
