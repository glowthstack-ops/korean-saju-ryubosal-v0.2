### 1-2. 점수식 (`_luck_effect`)

```
stem_eff.score   = +1 / −1 / 0           (천간 표면 오행 ∈ useful / unfavorable / 그 외)        _stem_effect 71~75
branch_eff.score = Σ weight_i · sign_i   (지장간 정기·중기·여기 가중합, sign ∈ {+1,−1,0})      _branch_effect 78~92
_branch_dynamics: 공망 ×0.60 / 충 ×0.80 / 공망+충 ×0.65 (방향 유지, 사건성·신뢰도 메타만 추가)  138~195
mitigation(HAP_MITIGATION_ENABLED, 기본 OFF): 기신 글자 합거 시 ×0.5                             251~261
rel_mod = Σ(합 변환 오행: 용신 +0.10 / 기신 −0.10), clamp ±0.2; 희용신 합반 시 −0.1             _relation_modifier 123~133
luck_score = w_s·stem + w_b·branch + rel_mod
   _PERIOD_WEIGHTS: daewoon (0.35, 0.65) · year (0.45, 0.55) · month/day (0.40, 0.60)            50~53
라벨: _luck_label(stem_type, branch_type, strong) — 점수와 별개로 천간/지지 type 조합으로 결정   198~222
```
`useful`/`unfavorable` = `manse_service._luck_role_sets` (375~384): final 용신+희신 / 기신+구신. 한신은 0.

### 1-3. 대운 식과의 차이

- 식 자체는 동일(`_luck_effect` 공용). 차이는 ① 가중 (0.35/0.65 vs 0.45/0.55) ② 대운은 합거 완화·구조 배경 미적용 ③ 세운은 `samjae` 필드만 추가. 모두 **원국 대비 독립 평가**다.
- **세운 점수는 대운 맥락(대운 천간·지지와의 합충, 대운 극성)을 전혀 참조하지 않는다.** `_yearly`/`_luck_pillar`의 시그니처에 대운이 없고, 관계 함수는 `pillars`(원국)만 본다.
- 결과적으로 세운 점수는 **"원국 × 60갑자" 60개 값의 순환**이다. 같은 연간지가 어느 대운에 떨어지든 점수가 같다(예: 071/L 1981 辛酉 +1.10은 1921·2041년에도 동일). 리포트 §3 표에서 072 L/R처럼 같은 사례의 다른 대운 구간에 같은 간지가 반복될 때 점수가 그대로 반복되는 것으로 확인된다.

가설 ①("대운 지배가 세운 luck_score에 반영되지 않는다") — **코드로 확인, 성립.**

### 3-1. 관찰

1. **다년 집계(e) 13건은 지표 설계 문제다.** 대운 구간·연령 구간 사건은 10~49개 연도 세운 평균을 쓰는데, 60갑자 순환에서 세운 부호는 거의 반반이라 평균이 ±0.05 중립대로 수렴한다(023: +4/0 4/−2, 025: +17/−20, 077: +26/−20). 이 13건은 세운 식을 고쳐도 평균으로는 못 맞춘다. 대운 점수를 섞으면 맞는 이유는 평균이 0 근처라 대운 부호가 그대로 통과하기 때문이다.
2. **단일 연도 불일치 15건의 내역: a 7(010/R, 034/L, 035/R, 039/R, 055/L, 071/L, 071/R) · b 7(010/L, 038/R, 049/R, 053/R, 077/R-58, 079/L, 085/R) · c 1(036/L, 대운 0.00).** a 7건 중 블렌드 w≥0.5로 구제되는 건은 세운이 ≈0인 4건(010/R, 034/L, 039/R, 055/L)뿐이고, 세운이 뚜렷한 반대 부호인 071/L(+1.10)·071/R(+0.45)은 w≤0.3, 035/R(−0.29 vs +0.14)은 대운 단독에서만 뒤집힌다. 동시에 018/R(세운 맞음·대운 틀림)을 잃어 단일 연도 일치는 9→12로 고정된다. b 7건은 용희신 배정(079/L 乙卯 +1.10인데 실패, 085/R 庚辰 −0.71인데 합격, 077/R 丙寅 −0.76인데 성공) 또는 건강·사망 채널 부재(010/L, 038/R, 049/R, 053/R — C5 범위)가 원인이며 대운 가중으로는 구제되지 않는다.
3. **세운-대운 간 충·합 패턴은 불일치를 설명하지 않는다.** 단일 연도 불일치 15건에서 세운-대운 지지충 0건, 육합 0건, 복음(간지동) 3건(010/L 庚寅-庚寅, 077/R 丙寅-丙寅, 039/R 丑-丑 지지동). 일치 9건도 비슷(천간합·삼합기여 각 1).
4. **"천간 용신·지지 기신" 혼합형이 원인이라는 가설도 약하다.** 불일치 15건 방향 분포: 용/용 3, 한/용 3, 기/용 3, 한/기 2, 기/기 2, 용/기 1, 용/한 1. 즉 **지지가 용신인데 결과가 흉인 건이 9/15**(일치 9건은 3/9). 흉 결과 12건 중 세운 지지 용신 8건. 이는 "용희신 지지가 들어와도 흉"이므로 지지 평가(지장간 가중합)보다 용신 배정·원국 관계 쪽이다.
5. **원국 관계 중 '충'이 불일치에 편중**: 불일치 15건 rels 충 11회 vs 일치 9건 충 2회. 현재 충은 ×0.80(방향 유지)만 깎는다. "충발 용신운"으로 라벨된 해(예: 071/R 壬戌 — 戌이 원국 辰 충?)가 실제로는 흉으로 귀결되는 경향 — 충의 흉 가중이 너무 약하거나 방향 전환 규칙이 없다는 신호다(단 n=15라 확정 아님).
6. **중립대 eps=0.05 민감**: eps=0이면 세운 20/43·대운 27/43, eps=0.1이면 9/43·21/43. 세운 |mean|<0.05인 건이 다수(010/R, 034/L, 039/R, 023 L/R, 025/R, 051/L, 057/R, 072×2, 077/R, 084/R)라 "틀림"이 아니라 "무신호"에 가깝다.

## 5. 결론

### 5-1. 원인 가설(근거 순)

1. **[확인] 세운 luck_score는 대운 무관한 원국×60갑자 순환값이다.** `_yearly` → `_luck_pillar` → `_luck_effect`에 대운 입력이 없고 관계도 원국 대비만 계산한다(§1). 가설은 코드로 성립한다. 다만 이것이 불일치 29건의 주원인이라는 증거는 약하다(2·3).
2. **[측정] 다년 집계 지표가 세운 부호를 지운다(e=13/29).** `casebook_report._domain_hits`가 구간 사건에 세운 평균을 쓰는 한, 세운 식을 어떻게 고쳐도 평균은 0으로 수렴한다. 지표 보정이 선행돼야 세운 식 변경 효과를 측정할 수 있다.
3. **[측정] 단일 연도 불일치 15건 중 9건은 대운도 같은 방향으로 틀렸다.** 용희신 배정(079/L, 085/R, 077/R-58)과 건강·사망 채널(010/L, 038/R, 049/R, 036/L, 053/R)이 원인이며 C1~C2·C5 범위다. 대운 가중으로는 구제되지 않는다.
4. **[관찰] 충 동태 가중 부족 가능성.** 불일치 건에 원국 충이 편중(11 vs 2). 현재 충은 ×0.8 완화만이고 "충발 용신운"의 방향 반전 규칙이 없다. 규칙 추가는 절대원칙 10에 따라 사용자 승인 사항(여기서는 보고만).
5. **[관찰] 중립대 eps=0.05 민감도.** 세운 |mean|<0.05 건 12건은 "틀림"이 아닌 "무신호"다.

## 요약 (10줄 이내)

1. 세운 luck_score는 `_yearly→_luck_pillar→_luck_effect`에서 원국 대비만 계산되며 대운 간지·극성을 전혀 참조하지 않는다 — 가설 성립(코드 확인). 같은 연간지는 어느 대운에서든 같은 점수다.
2. `period_hierarchy` 플래그는 LLM grounding 서술 전용이고 점수 가중이 아니다. 이벤트 엔진의 대운 반영은 거버닝 스택(신호 공급)·합화 배경·교운 부스트이며 luck_score와 무관하다.
3. 불일치 29건 = a(대운 맞음) 18 · b(둘 다 틀림) 9 · c(대운 중립/데이터 없음) 2. 다년 평균(e) 13건은 세운 부호를 지우는 지표 설계 문제.
4. 단일 연도 24건에서는 세운 9/대운 12이고, 대운 가중으로 구제되는 건은 4건뿐(어떤 w에서도 12/24 상한). 나머지 9건은 용희신 배정·건강 채널(C1~C2·C5 범위).
5. 블렌드 w=0.7/0.6→21, 0.5→24(54.5%), 0.3→27, 대운 단독 26; 상실 007/A·018/R·024/1(·079/R). 대운지배 게이트(|대운|≥0.3)도 24.
6. 세운-대운 충/합 패턴은 불일치를 설명하지 않는다(단일 불일치 15건 중 충·육합 0). 대신 원국 충 편중(11 vs 2)과 "지지 용신인데 흉 결과" 9/15가 관찰된다.
7. 권장: A 지표 보정(구간 사건은 세운 지표 제외) 선행 → B/C를 플래그 OFF·별도 필드(`daewoon_context_score`)로 구현해 재측정. 기존 luck_score·라벨은 불변 유지(samjae_quality·relations_engines·프론트 재계산과의 이중 반영 방지).
8. 세운 luck_score 수치를 고정한 테스트는 없다(라벨은 대운만, 월운은 플래그 on/off 관계식만). 신규 필드는 기본값 None이어야 수동 LuckPillar 생성 테스트 5종이 깨지지 않는다.

개선·악화 사례(단일 연도):
- 공통 개선: 010/R 심장 수술, 034/L 오토바이 사고, 039/R 사망, 055/L 노숙, 071/R 아내 이탈 — 전부 세운 |점수|≤0.45 이고 대운이 뚜렷한 흉(−0.35~−0.87). gate 는 071/L(세운 +1.10, 대운 −0.62)까지 뒤집는다.
- 공통 악화: **018/R 辛未년 사업 성장(+, 세운 +0.09 → blend −0.31 / gate −0.47)** — §F8 "잘 맞춘 지점" 목록의 사례. 대운 乙亥 −0.71 이 세운을 덮는다. blend 는 079/R(+0.10→+0.05, 중립대 진입)도 잃는다.

판단:
1. **대운이 중복 반영되는가** — 아니다. 새 필드를 읽는 운영 코드가 없고(실험 전용), 기존 소비자(`samjae_quality`·`relations_engines`·프론트)는 `luck_score`만 읽는다. 데이터로도 원본 0건 차이.
2. **세운의 독립 변화가 대운에 묻히는가** — 묻힌다. 전 연도의 약 1/4(blend 25.4%, gate 26.9%)에서 세운 부호가 뒤집히고, 대운 부호 일치율이 42%→66~72%로 오른다. 즉 맥락 점수는 "세운 신호"라기보다 "대운에 세운을 얹은 값"에 가깝다. 단일 연도 개선 5~6건은 모두 세운이 약한 신호(|≤0.45|)였던 건이고, 세운이 강하고 맞았던 018/R은 손실된다.
3. **지표 상승은 실제 개선인가** — 단일 연도 10→13/15 는 내부 개선으로 기록할 수 있으나 44건 중 3~5건 차이(SE ±10%p)라 통계적 변별은 없다. 다년 구간 2→6~7 은 대운 부호를 복제한 효과다(§4 결론과 동일).
4. **운영 승격** — 하지 않는다. 사례집 자체로 조정한 값이라 일반화 검증이 없고(Vol.3·실상담 필요), 묻힘 비율이 커 세운 단독 질문("올해 어떤가")에 쓰면 대운 서술과 중복된다. 쓴다면 **gate 모드를 "대운이 뚜렷할 때 세운 극성 완화" 보조 신호**로, 세운 원본과 나란히 제시하는 형태가 한계다.

후속 후보(승인 사항): ① 묻힘을 줄이는 변형 — 세운 |점수|≥0.5 는 보호(원본 유지)하고 약한 세운만 대운에 기대는 "약신호 보정" ② 018/R·024/1 류(세운 맞음·대운 틀림)의 공통 특징 조사 ③ 운영 노출 없이 이벤트 엔진 fav 보조로만 시험.
