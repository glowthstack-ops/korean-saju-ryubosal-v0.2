# C4 — 격국 성패·그릇 지수 분석 결과 (2026-10-07)

상태: **분석 완료 — 결론은 "지금 가중 지수를 만들지 않는다"**. 데굴님 결정 대기 항목은 §5.
상위: `CASEBOOK_CALIBRATION_PLAN.md` §4 C4. 자료 신뢰 경계: 쌍의 우열은 사례집의 실제 사건 극성 합으로만 정했다
(용희기신·상세 해설 미사용).

## 1. 무엇을 측정했나

사례집 68쌍(같은 날·다른 시, 결과 극성이 다른 두 명식)에 대해 "더 잘 산 쪽의 값이 더 큰가"를 성분별로 셌다(동점 0.5).
성분은 전부 현재 엔진이 내는 값이다: 격국 성패 점수(`success_failure_score`)·격국 신뢰도·최종 가중치·활성 파격 수·구제 수·
용신 작동성(operability)·신강약 중심성·충형파해 수·합 수·특수격 확정·용신 신뢰도·용희신 투간 수·사전 극성 패턴 수(favorable/
unfavorable)·대운 극성 지수(lfi).

## 2. 결과 — 집계 성분은 전부 우연 수준

| 성분 | 쌍 정확도 | 값이 다른 쌍에서의 정확도 |
|---|---|---|
| 격국 성패 점수 | 47.1% | 47% (60/68 쌍에서 다름) |
| 용신 작동성 | 43.4% | 38% (37/68) |
| 충형파해 수(적을수록 +) | 53.7% | 56% (41/68) |
| 사전 unfavorable 패턴 수(적을수록 +) | 41.9% | **32%** (31/68) |
| 대운 극성 지수(lfi) | 54.4% | 55% (60/68) |
| 특수격 확정 | 49.3% | 40% (5/68) |
| 합성 A~E(z-정규화 합) | 43.4~50.7% | — |

68쌍의 표준오차가 약 ±6%p 이므로 어느 성분도 유의하게 우연을 넘지 않는다. 특히 **격국 성패 점수와 용신 작동성, 사전의
unfavorable 패턴 수는 방향이 거꾸로다**(불리 패턴이 많은 쪽이 더 잘 산 쪽에 있다). 가중 합으로 지수를 만들면 68쌍에 맞춘
과적합일 뿐 예측력이 생기지 않는다.

성패 점수의 분포도 문제다: 6요소 가중합이 p10/50/90 = −8.5/10.5/38 로 '반성반패(−10~40)' 구간에 몰려 사례집의 79%가
중성이다. 하지만 점수 순서 자체에 변별력이 없으므로(47%) 경계만 다시 잡아도 라벨 분포만 바뀐다(C3과 같은 성격).

작동성 계산**이다(C1·C2에서 교정한 축과 같은 지점, 아직 남은 부분).

## 4. 결론

1. **그릇 지수(가중 합)는 지금 만들지 않는다.** 근거가 되는 성분이 전부 우연 수준이라 68쌍 과적합이 된다. 계획서의 "쌍 비교
   65% 목표"는 지수 설계가 아니라 용신·작동성 판정 교정으로 접근해야 한다.
2. **용신 유력/무력 역방향은 1순위 조사 항목이다.** 9:15 / 14:8 은 작동성(operability) 계수나 용신 선택이 틀린 쪽을 가리킨다.
   사례: 070/R(庚寅시 수감, 용 火 '유력')·062/R(丁酉시 상황 불리, 용 土 '유력') vs 057/L·079/R(용신 '무력'인데 우세). 조사는
   C1-c(종격 검출기 통일)·C2 보류 항목(축 공식·규칙 B)과 함께 한 묶음으로 다루는 편이 낫다.
3. **패턴 방향 신호는 보존 가치가 있다**(비겁탈재·상관제살·식신생재·충동·합충병견·수화미제). 다만 이 표로 가중치를 정하면
   같은 68쌍에 맞춘 것이 되므로, 사용자 노출용 점수가 아니라 **shadow 평가 지표**(`chart_quality_shadow`)로만 두고 Vol.3
   사례가 쌓이면 재측정한다.
4. 성패 라벨 분포(79% 중성)는 별도 결정이다. 점수 순서에 변별력이 없으므로 경계 재설정은 라벨 체감용이며, C3처럼 분위수
   경계(성 ≥ p75≈30, 패 ≤ p20≈0)로 바꿀 수는 있다.

## 5. 결정 요청

1. 그릇 지수 가중합 **보류**에 동의하는지(계획서 C4 목표 재정의: "용신·작동성 판정 교정 → 쌍 비교 재측정").
2. 용신 유력/무력 역방향 조사를 C5보다 먼저 할지(권장: 먼저 — C5 건강 채널은 독립이라 순서 교환 가능).
3. 성패 라벨 분위수 경계(성 ≥30·패 ≤0) 적용 여부 — 적용하면 중성 79% → 약 55%, 골든 스냅샷은 `geokguk_main_structure`만
   고정하므로 영향 없음, 격국 성격 라벨을 읽는 리포트 문구는 바뀜.
4. 패턴 방향 shadow 지표(`chart_quality_shadow`, 사용자 비노출) 생성 여부.
