# 출생시간 미상(시주 없음) 처리 정책 (SSOT)

> 2026-10-06 데굴님 승인. docs/11 §"3주 모드"의 구현 명세이며, docs/06 birthChartSummary 의 시주
> 미상 필드를 정의한다. 원칙: **미상은 없음이 아니고, 불완전 정보는 확정이 아니다 — 특히 용희신.**

## 2. 계산 (`manse_service._hour_unknown_analysis`)

- 시간 미상이면 날짜 결정용으로만 정오를 쓰고(종전과 동일) 시주는 만들지 않는다.
- 12시진 대표 시각(짝수 정시 00:00 子 … 22:00 亥)으로 `calculate()` 를 돌려 후보별 신강 밴드·격국
  주격·용희기 조합·연월일주·대운수를 모은다. 23시대(야자시)는 대표 시각에서 제외하고 경계 경고로만.
- 항목별 `ConsensusItem(status, base, values)`: 값이 2종 이상이면 `differ` → `unconfirmed` 에 등재.
- 비용: 후보 12건 약 2.8초(차트 캐시로 1회). 결과는 `ManseV2Result.hour_unknown` 에 영속.

## 3. LLM 입력 (`context_reducer`, `structural_context.HOUR_UNKNOWN_DIRECTIVE`)

- 헤더: `[원국·명식 구조 — 엔진 확정값 · 시주 미상: 3기둥 기준, '미확정' 표기 항목은 확정값 아님]`.
- 강약·격국이 상이면 `미확정(시주 미상 — 후보 …)`. 용희신이 상이면 `useful_gods` 를 비우고
  "용신·희신·기신·구신·한신: 미확정(…길흉 판정·보완 색·방향·오행 처방에 쓰지 말 것)" 한 줄로 대체.
  후보 극성(`LlmEventCandidate.polarity`)은 `unconfirmed`("극성 보류")로 바꾸고, 오행 보완 색·방향
  첨언은 싣지 않는다(사용자 검증 확정 용신이 있으면 예외).
- 지시문(채팅 trailing·리포트 prefix 공통): ①1회 고지 ②시주 궁위(자녀·말년·결과·표출) 서술 금지
  ③'무X성·오행 부재' 전체 단정 금지 ④미확정 항목 인용 금지·용희신 미확정 시 길흉/처방 금지
  ⑤대운수·교운 범위 표현. 뒤에 `[엔진 산출]` 로 notice·경계 경고를 붙인다.
- 리포트 섹션 지침 교체(`_SECTION_GUIDES_HOUR_UNKNOWN`): F-04(강약·격국·용신), F-05(시=말년 자리
  신살), F-17c(자녀궁). 궁합(채팅·리포트)에는 `[궁합 한계]` 줄 추가.
- 엔진 내부 점수·선별은 바꾸지 않는다 — 노출 제한은 LLM 입력 계층에서만.

## 4. 화면 (`components/manse/HourUnknown.tsx`)

- `HourUnknownBanner`: 산출 불가 / 부분 확인 / 12시진 후보 비교(일치·상이) / 범위 / 경계.
- `GhostOverlay`: children 을 blur+반투명 처리하고 라벨을 덮는다 — **영역·크기는 유지**해 실제 데이터가
  있을 때 무엇이 보일지 짐작하게 한다(데굴님 지시). 적용: 시주 칸(예시 丙午), 신살 시주 열, 미확정
  신강약·격국·용신 값.
- `ConsensusBadge`: 일치="시주 후보 전부 일치", 상이="미확정 · 후보 …".
- 대운수는 범위로 표시. 용신 패널은 사용자가 검증·등록으로 확정한 값이 있으면 가리지 않는다.

## 5. 결함 수정

- `yongsin/candidates.py` 재성 투간 감점: 괄호 구조로 시주 미상이면 연간 판정까지 건너뛰던 결함 수정.

## 6. 엔진 극성 중립화 (2026-10-06 후속, 데굴님 지시)

`event_scoring.favorability_map(result)` 가 `hour_unknown.unconfirmed` 에 `useful_gods` 가 있으면 **빈
매핑**을 돌려준다. 사건 점수·위험·기회·관계·precompute·구조 패턴 등 이 함수를 쓰는 35개 호출처 전부가
극성을 중립(한신/NEUTRAL)으로 본다. 운 카드(`compute_luck_cycles`)의 용신운/기신운도 같은 조건에서
빈 집합으로 넘겨 평운이 된다(분석을 운 계산 앞으로 옮김). 사용자가 검증으로 확정한 용신은 호출부가
`fav_override` 로 따로 넘기므로 영향받지 않는다. 엔진 내부 점수 산식은 바꾸지 않았다.

## 7. 경계 당일 명식 분기와 변형별 분기 풀이 (2026-10-06 후속, 3차 확장)

- `pillar_variants`: 12시진 **전체**를 연·월·일주 조합으로 묶고(범위 좁히기와 무관하게 항상 전체),
  변형마다 핵심 사실을 모은다 — `day_master`·`strength_bands`·`geokguks`·`useful_gods`·
  `daewoon_directions`(변형 안에서도 갈리면 복수). `is_base` = 현재 표시(계산 기준) 명식.
- 현재 범위(hint/variant/band/all12) 안에서 연·월·일주가 갈리면 `unconfirmed` 에
  `year_pillar`/`month_branch`/`day_master`. 일주가 갈리면 그 위에 선 판정(신강약·격국·용희신)도 전부
  미확정.
- **변형 선택**(`BirthInput.hour_branch_candidates` = 그 변형의 시진 목록): 연·월·일주의 기준 시각을
  정오 대신 그 범위의 대표 시각(가운데 시진 짝수 정시)으로 잡아 **표시 명식 자체가 그 변형**이 된다
  (`manse_service._unknown_anchor`, manse_core 무수정 어댑터). 시주는 여전히 None. `basis=variant:…`,
  notice "선택한 변형 기준으로 표시 중(확정 아님)". 변형 목록은 그대로 남아 되돌릴 수 있다.
- **LLM 분기 풀이**: `[시주 미상 — 확정 제외·해석 제한]` 줄에 "명식 변형(경계 당일 — 변형별 분기 풀이
  대상): [A] 癸卯·乙丑·戊戌(子~申시 — 현재 표시) 일간 戊 · 강약 … · 격국 … · 용희기 … · 대운 순행 /
  [B] …" 를 싣고, 지시문 7항이 **변형별로 나누어 서술하고 하나를 고르지 말 것**, 시기 후보·점수는
  현재 표시 변형 기준임을 밝힐 것, 변형을 골랐으면 '선택한 변형 기준(확정 아님)' 고지를 요구한다.
- **변형별 사건 점수 완전 분기**(`services/variant_branching.py`, 4차): 표시 변형을 뺀 변형마다
  `hour_branch_candidates` 로 그 변형을 고른 BirthInput 을 `calculate()` 하고 같은 scorer 의 `score_legacy`
  로 따로 채점한다. 범위는 표시 변형의 선별 후보가 있는 월·연 집합(없으면 보고서 연 범위) — 같은 창에서
  비교하기 위해서. 변형당 상위 5건을 `[명식 변형 B 시기 후보 — … 명식으로 따로 채점]` 블록으로 싣고
  "차이 — 표시 변형에만/변형 B에만" 줄을 붙인다. 채팅은 structural 블록 끝에, 리포트는 전 섹션 공통
  prefix 에 들어간다. 보조 채점이 싱글턴 scorer 의 shadow 상태를 덮지 않도록 호출 뒤 비운다.
  지시문 7항: 블록이 있으면 시기도 변형마다 그 블록 후보로 나누어 서술(합산·평균 금지).
- 화면: `PillarBoard` 상단 명식 분기 스트립 — 변형별 [A]/[B] 카드(일간·강약·격국·대운 방향),
  '이 변형으로 보기'/'선택 해제(정오 기준)'. 선택은 프로필·DB(`hour_branch_candidates`)에 저장.
- 실측: 2024-02-04(입춘 17:20 KST) 서울 → [A] 癸卯·乙丑·戊戌(子~申) / [B] 甲辰·丙寅·戊戌(酉戌亥),
  대운 순행↔역행까지 갈린다.

## 8. 대략 시간대·성향 기반 후보 좁히기 (2026-10-06 후속)

- `BirthInput.birth_time_approx`(새벽/아침/낮/저녁/밤)·`hour_branch_hint`(子~亥). 시간대 → 시진:
  새벽 寅卯(03~07) / 아침 辰巳(07~11) / 낮 午未(11~15) / 저녁 申酉(15~19) / 밤 戌亥子丑(19~03).
- 후보 집합 우선순위: 추정 시진 > 시간대 > 12시진 전체(`basis` = hint:/band:/all12).
- `POST /api/v2/manse/hour-traits`: 후보 시진별 성향 문장 — 시주 천간 십성·시지 본기 십성·12운성의
  사전 natal 문구(`ten_gods_text`·`twelve_stages_text`) 그대로, 즉석 작문 없음. 화면은 어느 시진의
  문장인지 가리고 결정론 섞기로 보여 준다(선입견 방지).
- `POST /api/v2/manse/hour-narrow`: 고른 문장 수로 순위. 단독 1위이고 2개 이상 일치할 때만 추천
  (격차 2 이상 medium, 아니면 low). 결과는 **추정**이다.
- 추정 적용(`hour_branch_hint`) 후에도 `pillars.hour=None`(시간 미상 모드 유지). LLM 헤더는
  `hour:추정 辛未(성향 기반·확정 아님)`, 강약·격국은 "추정 시진 기준(3기둥만으론 …)" 병기, 지시문 6항이
  궁위 서술 금지와 '추정 시진 기준' 고지를 요구한다. 화면 배너는 추정임을 명시하고 패널에서 해제 가능.
- 저장: 로그인 사주는 `subjects.birth` 에 영속(PUT), 비로그인은 기기 프로필.

## 10. 도화·화개 상대 기준 전환 (2026-10-06 3차)

역마와 같은 원칙으로 집계기(`sinsal_aggregator`)의 도화·화개도 글자살을 버리고 연지·일지 삼합국 기준
상대 12신살(년살→표시명 '도화', 화개살)로 산출한다. 子午卯酉·辰戌丑未 글자 보유는 '사정지'·'사고지'
표지(`BRANCH_MARKER_NAMES` — 파생 해석·LLM 노출 제외)로만 남는다. 표시명 '도화'·'화개살'은 사전·FE
호환을 위해 유지. 운 신살(`sinsal_for_luck`)도 동일. 궁합·배우자 자원·외적 인상 엔진은 자체 사정지
로직을 쓰며 영향 없음. 실측 1990-03-15 14:30 庚午·己卯·己卯·辛未: 연지 午 기준 도화 卯(월·일), 일지 卯
기준 화개 未(시) + 사정지×3·사고지×1 표지.
