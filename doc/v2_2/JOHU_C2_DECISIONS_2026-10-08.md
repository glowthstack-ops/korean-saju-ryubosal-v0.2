# C2 조후 — 남은 결정 묶음 정리 (2026-10-08, 채택 / 기각 / 근거 부족 구분)

> 데굴님 지시: 규칙 B·축 모드부터 결정하고, conditions 소비·개별 보류 항목 순으로 정리해 결정 대기를 줄인다. 아래는 결정안이며 적용은 승인 후.

## 1. 규칙 B — 최저 역할 보장(floor)

| 항목 | 내용 |
|---|---|
| 정의 | 최종 5역할 확정 뒤, 기후 축 mild 이상 ∧ 조후 후보 오행 확정이면 그 오행은 기·구신 금지(B-1 최저 한신) / severe ∧ 교정 글자 부재면 최저 희신(B-2) |
| 근거 사례(C2 당시) | 042 L/R(severe_heat 74, 壬癸 부재 → 水 구신), 063/L(癸 투간·severe_heat → 水 구신) |
| 현재 상태 | 063/L 은 종격 통합으로 억부 木/水/火/土/金 → **水가 이미 희신**(규칙 B 없이 해소). 042 L/R 은 미확인 — 최신 재생에서 재확인 필요 |
| 결정안 | **B-1(최저 한신)만 채택 검토, B-2 기각**. B-2는 억부 희신 자리를 조후가 빼앗아 용신 모델 간 경쟁 원칙(축 가중)과 충돌. B-1 도 "역할표를 사후에 고치는 floor" 라 축 가중 체계 밖의 예외이므로 **근거 부족 → 보류**가 안전. 042 가 재생에서 여전히 水 구신이면 그때 B-1 재논의 |
| 분류 | B-1 **근거 부족(보류)** · B-2 **기각** |

## 2. 축 모드 — `axis_graded`(월지 무관) vs 현행 `month_axis_graded`

| 항목 | 내용 |
|---|---|
| 쟁점 | 축 공식(`_climate_axes`: 분포 火−水 + 지지 가중 ±5/±10)이 분포 중심이라 卯·辰월에서도 발동하고, 丑月 창원 2018 기준 사주가 neutral 로 빠짐 → 월지 무관 모드 보류 |
| 대안(월령 가중) | temp 식에 월지 항을 키움: 한난 월지(亥子丑/巳午未) ±15(현행 ±5와 별도, 월지만), 조습 월지 丑辰/未戌 ±15. 임계 20/40 유지 |
| 판단 | 월령 가중을 넣으면 `month_axis_graded`(한난 월 필요조건)와 사실상 같은 방향이 되어 두 모드의 차이가 "한난 월 밖 극단 분포"로만 남는다. 그 사례(卯·辰월 severe)는 사례집에서 조후 강등 오탐으로 분류됐던 유형 |
| 결정안 | **현행 `month_axis_graded` 채택 확정, `axis_graded` 기각**(월지 무관 모드 코드 분기는 유지하되 운영 선택지에서 제외). 월령 가중 공식은 별도 과제로 두지 않음 |
| 분류 | **채택(현행)** / axis_graded **기각** |

## 3. conditions[] 소비 규칙

| 항목 | 내용 |
|---|---|
| 현황 | 사전 `conditions_schema`만 정의, 17건 초안은 감수 보고 §4, 엔진 미소비 |
| 소비 설계안 | when 4종 중 **half_month**(절기 상·하반)·**natal_excess**(오행 비율 임계)만 1차 — 결정성 있음. natal_has(국 성립)·birth_hour(주야)는 2차 |
| 효과 | relation 재정렬(pri↔alt)만 — climate 후보 집합은 불변 → 최우선 글자만 바뀜(천간 단위) |
| 결정안 | **근거 부족(보류)** — 17건 중 한난 월 조후 후보에 실제 영향이 있는 것은 half_month 5건(甲未·乙午·壬丑·癸未·乙未)인데 해당 명식이 사례집에 거의 없어 측정 불가. 사전 등재(conditions[])는 **채택**(문서→사전 이관, 엔진 미소비 명시) |
| 분류 | 등재 **채택** / 소비 **보류** |
