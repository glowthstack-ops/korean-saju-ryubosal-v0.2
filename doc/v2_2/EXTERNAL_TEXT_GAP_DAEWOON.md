# 외부 강의 대조 — 「대운이란 무엇인가」 vs 류보살 v2 엔진 (2026-10-29)

> 같은 강사의 재물·이직·이별·남녀 차이 강의와 짝. 강의 관점은 엔진의 대운 풀이 관점 지시(`DAEWOON_FRAMING_DIRECTIVE`)와 거의 같아, 실제 개선은 **대운 질문 라우팅 결함**과 서술 보강이다.

## 1. 강의 요지

- 대운은 좋은 운이 아니라 10년 단위로 바뀌어 들어오는 큰 운(대운수 3·13·23세 / 5·15·25세 식). 좋게도 나쁘게도 온다. 100년이면 10번.
- 사주(명)=차(불변), 운=달리는 길. 대운=계절, 세운=그 계절 속 하루·한 달. 사주불여대운.
- 좋은 대운 = 원국을 받쳐 주는 대운.
- 재성 대운이 와도 원국에 식상이 없으면 숟가락이 없는 격 — 손으로라도 떠먹는 노력이 있어야 내 것.
- 좋은 대운도 노력 없이는 소용없고, 나쁜 대운(예: 겁재 대운)은 미리 문단속하면 덜 버겁다.

## 2. 대조 (2026-10-29, 라이브 dry-run 포함)

| 강의 / 질문 | 엔진 | 판정 |
|---|---|---|
| 대운 ≠ 좋은 운 | 관점 지시가 '맞는 대운이냐'를 핵심으로 둠. 사용자 오해 교정 문장 없음. | 서술 보강 |
| 대운수·교운 | 압축 간지달력에 대운별 나이·교운일. | 동등 |
| 계절·위계 | '계절이 닥치듯 바뀌는 10년'·대운=배경/세운=사건화. | 동등 |
| 좋은 대운 = 원국을 받쳐 줌 | 채팅은 대운별 역할 라벨. **리포트 십년 풀이 페이지 머리줄에 역할 라벨 없음.** | 결함 |
| 재성 대운 × 원국 식상 | 재물 보완 문구가 재물 질문 월·연 후보에만, 대운 단위 없음. | 서술 보강 |
| 노력·대비 | '기신 구간은 지키며 준비'만. | 서술 보강 |
| "지금 대운은 어때요?" | 시간 파서 C14가 '다음·이번·현재 대운'만 → too_broad 반려. | 결함 |
| "언제쯤 대운이 들어오나요?" | 월 단위 일반 시기 탐색 → 대운 역할이 앞뒤 두 대운만. | 결함 |
| "제 인생에 좋은 대운은 언제?" | 위와 같음('평생'만 생애 범위, '제 인생' 미인식). | 결함 |

## 3. 데굴님 결정 (2026-10-29) — "모두 제안대로 진행할게"

P0 결함 4건 진행 / 대운 받을 준비는 강의 예시 범위(재성 대운 × 원국 식상)만 / 오해 교정 문구는 대운 시기를 묻는 질문에만.
