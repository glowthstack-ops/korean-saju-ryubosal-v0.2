# 구조 배합의 원국 세력 보정 판정(P0)과 운 적용 구조 상태(P1) — SSOT

> 2026-10-17 데굴님 승인("전부 승인", "기존 임계로 충분", 확장 4건 "제안대로"). 상위 설계: docs/13(구조 패턴), HOUR_UNKNOWN_POLICY §8, docs/09(사전계산 T1).
> 외부 검토 글 2편(재다신약 운 변화 / 4조합 운 변화)을 계산 가능한 규칙으로 번역한 문서다. 글의 "일운 단기 촉발 반영"은 채택하지 않는다(일운 제외).

## 0. 원칙(불변)

1. **성립 ≠ 길흉.** `DetectedPattern.favorability` 는 비운 채 유지. 상태(강화·완화)는 길흉 판정이 아니다 — 상관생재 강화가 재물 상승을 뜻하지 않는다(자평진전 성격·변격 ≠ 길흉).
2. **점수·용신·신강약 불변.** P0·P1 은 서술·표시 전용(inert). 신강약 band 는 원국 고정이며 운 적용으로 재판정하지 않는다.
3. **사전계산 우선(원칙 9).** P1 상태는 `LuckComposite.pattern_states`(T1: 대운·세운·월운)에 저장. 즉석 빌드는 기존 cache-aside 폴백(`report_service.composites`)과 익명 만세력 페이지(luck/months·calculate 운 스트립)만 — 저장값과 즉석값의 동일성은 `test_precompute_wiring` 과 같은 방식으로 강제한다.
4. **시주 미상은 미계산.** P0·P1 모두 `pillars.hour is None` 이면 건너뛰고 미확정(HOUR_UNKNOWN_POLICY §8). 12후보 합의 확장 없음.
5. **LLM 문구는 사전 치환만.** 상태 어휘·문장은 `dictionaries/structure_patterns.json` 의 `transit_text`(유형별)에서 읽는다. 즉석 작문 금지.
6. **격국 변격 보류, 합충 family 제외**(운 관계 계층이 이미 처리), 일운 제외(T2 플래그만).

## 1. P0 — 원국 세력 보정 2중 판정(억부 6종) — 구현 완료(2026-10-17)

대상: 재다신약·관다신약·인다신약·설기태과·군겁쟁재·비겁탈재.

| 기준 | 입력 | 임계(기존 값 그대로) |
|---|---|---|
| 개수(count) | 천간 3 + 지지 본기 4 = 7칸 개수(`_tg_counts`) — 기존 격국 파격 어댑터·신규 규칙 | 재성 30%·관성 2칸·인성 40%(+식재 ≤20%)·식상 35%·비겁 35%+재 10%·비겁 2칸+재 1칸 |
| 보정 세력(effective) | `force.ten_gods.effective_percent` 그룹 합(지장간 비율·자리 가중·월령 본기·투간·공망 0.85 반영) | **같은 임계.** 절대 칸수 규칙은 7칸 비율로 환산: 관성 2칸→28.5%, 비겁 2칸→28.5%, 재 1칸→14.3% |
| 신약 조건 | `force.strength.band ∈ {신약, 태신약}`(기존 `_WEAK_BANDS`) | 변경 없음(중화신약은 신약 아님) |

판정: 두 기준 모두 성립 → **뚜렷한 성립**(strength 0.8), 하나만 → **약한 성립**(0.5). 근거 줄 `basis_note` = "표면 29%·보정 세력 37%·신약 — 뚜렷한 성립". 개수 기준만 성립하던 기존 발동은 strength 0.5 로 내려간다(LLM 상위 6 순서가 바뀔 수 있음 — 점수 아님). 재다(개수)와 재왕(세력)을 구분하는 효과.

`DetectedPattern.basis_note`(신규, 기본 "") — 화면 줄 끝·`llm_line` 끝에 붙는다.

### 2-2. 구조 성립과 현재 작동의 분리

`PatternState { pattern_id, natal_established: bool, operating: bool, status_vs_natal, status_vs_parent, strength_natal, strength_operating, activation_sources: [daewoon|year|month], evidence: [str], flags: [burden|over_control|competition] }`

- 층 누적: 대운(원국+대운) → 세운(+세운) → 월운(+월운). `status_vs_parent` 는 바로 위 층 상태와 비교.
- **월운 층은 '해소'를 쓰지 않는다** — 최대 '완화(일시 차단)'. 해소는 대운·세운 층에서만. (대운 성립 구조가 월운 인성으로 약해져도 구조 자체가 사라진 것은 아니다.)
- `natal_established` 는 원국 감지(P0 포함)에서 고정. 운에서 신규 성립한 것은 `natal_established=False, operating=True`.

### 2-3. 공통 계산 입력(전부 기존 산출물)

- **운 적용 세력** `luck_adjusted_groups`: 원국 `effective_percent` 분포에 운 천간(투간 가중)·운 지지(지장간 비율 `hidden_stems_for`)를 층 비중 `_PERIOD_WEIGHTS`(대운 0.35/0.65, 세운 0.45/0.55, 월운 0.40/0.60)로 더해 재정규화. 상위 층 글자는 누적 포함.
  - 합반(`BindingState.BOUND`) 글자 ×0.5, 합거(`REMOVED`) 글자 제거, 합화 확정(`TRANSFORMED`) 글자는 `transform_element` 로 전환(relation_semantics·snapshot `resolved_element` 확정만), 충 받은 원국 지지 ×0.7(충동·충개 — 환원 전이 결과 우선), 공망 충발은 기존 규칙(지연 아님, 활성화) 그대로 읽어 감산하지 않는다.
- **유근**: `hap_modes._rooted` 와 같은 방식 — 해당 오행이 원국 지지 또는 운 지지 지장간에 있는가.
- **손상(유효성)**: 패턴 핵심 글자가 합반·합거·충 중 하나면 손상. 용신 operability 의 손상 인자와 같은 어휘.
- 세력 변화 임계 **±5%p**(강화·완화 판정).

### 2-4. 유형별 조건

- **T1 생극(A→B)**: 작동 = A·B 운 적용 세력 각 ≥10% ∧ 둘 다 비손상 ∧ A의 극제자(예: 상관의 인성)가 A보다 강하지 않음. 강화 = 작동 유지 + (A+B) ≥ +5%p 또는 손상 해소. 완화 = 작동 유지 + (A+B) ≤ −5%p 또는 핵심 글자 손상 또는 극제자 ≥ A. 해소 = 작동 ✗(대운·세운 층). 플래그 `burden`: 원국 신약계 ∧ 식상+재 운 적용 합 ≥50%.
- **T2 제어·배합(상관패인 기준, 나머지 동일 틀)**: 작동 = 피제어자(상관) ≥20% ∧ 제어자(인성) 유근 ∧ ≥10% ∧ 역제자(재성) < 제어자. 플래그 `over_control`: 제어자 ≥ 피제어자×2(강화 아님). 완화 = 역제자 ≥ 제어자 또는 제어자 손상. 해소 = 피제어자 <10%(패인 필요 구조 소멸) 또는 제어자 작동 ✗.
- **T3 억부·과다**: P0 임계(보정 세력)를 운 적용 세력에 적용. 신강약 band 는 원국 고정 → 강화·완화는 '부담 그룹 ↑ ∧ 일간 측(비겁+인성) ↓' / 반대로 판정. **신규 성립은 원국 band 가 신약계일 때만**(중화 원국의 재성 우세는 재다신약으로 만들지 않는다 — 재다≠재왕). 오행 과다 물상은 그룹 대신 오행 세력(`season_adjusted_element_strength` 운 적용)으로 같은 틀.
- **T4 균형(수화기제)** *(2026-11-13 §6-5 로 대체 — 원국 감지와 같은 조건 함수)*: 활성 = 水·火 운 적용 세력 둘 다 8~40% ∧ 비율 0.5~2.0. 약화 = 한쪽 구간 밖. 중단 = 한쪽 합거·충 손상 또는 비율 >3. 조후 4종·천한지동은 같은 틀(대상 오행 쌍은 사전 `balance_pair`).
- **T5 천간 배합(정화련금 기준)**: 충족 = 丁·庚 동시(원국 또는 운 보충) ∧ 金 운 적용 세력 ≥15% ∧ (丁 유근 ∨ 甲 존재) ∧ 水 < 火. 약화 = 조건 중 하나 상실. 상실 = 丁 또는 庚 합거·충 손상. 나머지 7종은 사전 `stem_pair`·`helper`·`blocker` 로 같은 틀.

### 2-5. 조합 간 경쟁(상관생재 × 인성운 기준)

운 글자는 위치 없이 원국 전체에 닿으므로 접촉은 세력 비교로 정한다.
1. 인성 < 재성 → 상관생재 '완화'만. 상관패인 생성 금지.
2. 인성 유근 ∧ 인성 ≥ 상관/2 ∧ 인성 > 재성 → 상관패인 '신규 성립' + 상관생재 '완화' 병기.
3. 둘 다 작동 조건 충족 → 병존, 양쪽 `competition` 플래그.
같은 틀: 식신제살 × 인성운(인극식), 재생관 × 비겁운(겁재탈재).

### 2-6. 저장·노출

- 저장: `LuckComposite.pattern_states: list[PatternState]`(대운·세운·월운). 스키마 추가 → `dict_version` 상승 → T1 재계산.
- 만세력 페이지: 세운·월운 카드 하단 "구조 변화" 1줄(상태 어휘 + 패턴명, 최대 3개, 강도순). 익명 입력은 `luck/months`·calculate 운 스트립에서 같은 순수 함수 호출.
- 채팅·리포트: 해당 기간 블록에 `[구조 변화]` 최대 3줄(사전 문구). 토큰 한도 기존 유지. 기존 섹션 안 문장이며 목차 변경 없음.
- 점수 반영 없음. 실사례 적중률을 본 뒤 별도 결정.

### 6-1. 化 세력은 그룹에만

合化로 넘어간 세력은 化 오행의 십성 **그룹** 세력(`AdjustedStrength.groups`·`transformed_groups`)에만 더하고 `ten_gods`(정·편)에는 넣지 않는다. `group(tgs)` 는 목록이 그룹 전체면 그룹 세력(化 포함), 정·편 지정이면 실제 글자 세력만 돌려준다(`pattern_conditions.full_group_of`). 따라서 정관·편관·식신·상관·편인·겁재가 지정된 다리는 글자가 있어야 선다. 化 세력으로 선 **운 생성** 그룹 단위 배합에는 표지 `via_transform`("합화(合化)로 바뀐 세력이 포함됨")를 단다(원국 성립 패턴에는 달지 않는다).
- 근거: 化 자체는 《子平真詮》 論十干合而不合 해설의 월령·통근 조건(丁壬化木 = 卯월 또는 지지 寅·亥)에 맞지만, **化神의 음양(정·편)을 정하는 규칙은 검색에서 찾지 못했다** — 반반 배분은 근거 없는 근사였다.

### 6-2. 신규 성립 = 운 글자의 직접 기여(`ContributionSpec`·`_contributes`)

운 생성 패턴이 어떤 층에서 새로 켜지려면 **그 층의 운 글자**가 아래 중 하나를 해야 한다.
1. 운 천간 또는 운 지지 **본기**의 십성이 다리에 든다(정·편 일치).
2. 확정 化·局의 그룹이 **그룹 전체 다리**와 같다.
3. 그 층에서 원국의 **차단자** 그룹 글자가 합·충·化로 새로 덜어졌다(救應).

한번 선 운 생성 상태는 하위 층에서 조건이 유지되는 동안 이어진다. 다리·차단자 표는 `pattern_conditions.contribution_spec`(T1·T2)과 `pattern_transit._transit_contribution_spec`(T3 억부 6종·T4 수화)에 있다. T5 천간 배합은 글자 출현이 조건이라 게이트가 없다.
- 근거: 《子平真詮》 論行運成格變格 "何為成格？本命用神，成而未全，從而就之者是也" — 예시는 운 지지가 원국과 회국하거나(會) 운 천간이 원국 지장간을 투출하는(透) 경우뿐. 같은 장의 변격 예시 "運逢戊土，透出戌中七煞"(칠살이 섞이는 것은 살 글자가 실제로 올 때). 論支中喜忌逢運透清 "逢運透清，則靜而待用者，正得其用"(지장간은 투출될 때 쓰인다 — 운 지지의 여기·중기만으로 다리를 세우지 않는다).

### 6-3. 재생관·재생살 배타(가안 채택)

정관·편관이 둘 다 10%+ 이면 **강한 쪽 이름 하나만** 성립하고 표지 `mixed_officer`("정관·편관이 함께 있는 관살혼잡")를 단다. 세력이 같으면 재생살. 원국 감지도 같은 함수라 원국에서도 함께 서지 않는다. 재관인상생의 '재→정관 다리'는 배타 적용 전 조건(`exclusive=False`)으로 본다.
- 근거: 論財 "財旺生官者，身強而不透傷官，不混七煞，貴格也", 취운 "運喜身旺印綬，不利七煞傷官". 재와 살이 함께인 경우는 "有財帶七煞者…"로 따로 다룬다.

### 6-4. 제살태과

- 신규 전제 = 원국 **편관 5%+(실제 글자)** ∧ 식상 존재(종전: 관살 그룹 5%+).
- 편관을 공급하는 운에서는 신규 성립하지 않는다(`ContributionSpec.veto`).
- 제살태과 조건이 서면 식신제살·상관제살·관살유제는 성립하지 않는다(`jesal_taegwa_ok`). 종전 `excessive` 표지는 삭제(제살 과다는 제살태과 한 줄로만).
- 근거: 論偏官 "至書有制煞不可太過之說，雖亦有理，然運行財印，亦能發福"(재·인 운에 풀린다 — 살을 보태는 운에 '성립'하는 구조가 아니다), 《淵海子平》 論偏官 "制伏復行制伏運謂之太過".

### 6-5. 수화기제·미제 — 원국 감지와 한 함수(`pattern_conditions.evaluate_suhwa`)

기제 = 水·火 둘 다 15%+ ∧ 둘 다 결핍 아님 ∧ 차 15 이내. 미제 = 기제가 아니면서 한쪽 결핍(9% 미만) 또는 차 30 이상. 그 사이는 어느 쪽도 아니다(종전 운 판정은 '기제가 아니면 전부 미제'). 신규 전제 = 원국 水·火 각 8%+(종전 '0 초과'). 지표는 차(%p) 기준(기제 = 100 − 차, 미제 = 차). `broken` 표지는 실제 손상(합거·충)일 때만.
- 남은 차이: 원국 감지기는 표면 세력(`visible_percent`), 운 판정은 보정 세력 기반 오행 몫을 넣는다. 원국 성립인데 운 모델 기준으로는 원국부터 미충족인 경우는 종전 규칙대로 '성립 고정'이며, 운에서 맞수(미제)가 실제로 서면 그 층에서 중단으로 표시한다(§6-6 ④).
- 명리 정의는 출처마다 달라(상하 위치·납음·세력) 외부 근거가 아니라 내부 조건 불일치로 교정했다.

### 6-6. 무관한 운은 상태를 바꾸지 않는다(`_related_groups`·`_touches`) + 맞수 정리(`_RIVALS`)

층별 상태를 (작동, 지표) 연쇄로 잇는다.
1. 운 천간·지지 본기의 십성 그룹(또는 化 그룹)이 패턴의 관련 그룹(다리·차단자·주 세력과 그 극제자)에 들지 않고, 그 층에서 원국의 관련 그룹 글자가 덜어지지도 않았으면 **직전 층 상태를 그대로 잇는다** — 희석만으로 완화·해소·강화를 내지 않는다.
2. 운 생성 패턴은 §6-2 기여가 있어야 새로 켜진다.
3. 원국 성립인데 운 모델 조건이 원국부터 미충족인 패턴은 종전대로 성립 고정(세력 변화만).
4. 맞수 구조(재생관↔재생살, 수화기제↔미제, 제살태과↔식신제살·상관제살·관살유제, 관살유제↔살중제경)는 한 층에서 함께 켜지지 않는다. 먼저 서 있던 쪽이 남고 새로 켜진 쪽이 꺼지며, 성립 고정(3) 원국 패턴은 운에서 실제로 선 맞수에게 자리를 내준다.

**기각한 대안(측정)**: '재정규화 없이 원국 합 100 단위 유지'는 완화를 줄이지만(T1 376→96) 신규가 2,555→3,050건(+19%)으로 늘고 강화 쪽으로 치우쳐(T3 강화 584→1,188) 채택하지 않았다.

### 6-7. 관살유제 재정의

성립 = 관살 20%+ ∧ 식상 10%+·유근 ∧ **관살/2 ≤ 식상 < 관살×2** ∧ 인성 < 식상(인극식 방해 없음) ∧ 식상·관살 비손상 ∧ 제살태과 아님. 재 ≥ 식상이면 표지 `wealth_feeds_killing`. 종전의 '인성만 있어도 성립'은 폐기 — 인성은 化(살인상생·살중용인)다. 하한 1/2 은 살중제경(제화 < 관살/2), 상한 2배는 제살태과의 기존 비율이라 세 구조가 겹치지 않는다(`LIGHT_CONTROL_RATIO`).
- 근거: 《淵海子平》 論偏官 "有制伏則為偏官，無制伏則為七殺"·"身旺化之得為偏官"(制와 化를 구분), 《子平真詮》 論偏官 "煞用食制者，上也，煞旺食強而身健，極為貴格"·"亦有煞重身輕，用食則身不能當，不若轉而就印"(인성은 별도 경로)·"煞用食制，不要露財透印，以財能轉食生煞，而印能去食護煞也"·"有煞而雜官者，或去官，或去煞，取清則貴".

### 7-0. 결함

엔진은 일간이 힘을 써야 하는 구조를 판정할 때 일간 강약을 거의 보지 않았다(예외: 상관패인·재자약살·식상설수). 무작위 150명식 중 신약·태신약 41명식(대운 410개) 실측:
1. 생재 3종·재생관·식신제살·상관제살·관살유제·살중용식 8종이 신약 원국에서도 운에서 '신규 성립' — 171건.
2. '부담' 표지(`burden`)는 생재·재생관에 식상+재 50%+ 일 때만(95건 중 55건), 제살 계열 76건에는 없음.
3. 일간을 받치는 글자(비겁·인성)가 합·충으로 빠진 것을 '차단자가 덜어져 길이 열렸다'로 읽음 — 데굴님 壬辰 대운의 식상생재·상관생재(월간 편인 丁이 丁壬合으로 빠짐).
4. 신약 원국에 성립한 구조가 비겁·인성만 오는 대운(幫身 운) 101건 중 86건에서 해소·완화 — 고전은 이 운을 그 구조에 가장 좋은 운으로 본다.

### 7-1. 근거

- 《子平真詮》 論食神 "身強食旺而財透，大貴之格", 論食神取運 "食神生財之局，因身輕身重而不同。身重喜行財食，身輕則喜幫身", 평주 "身輕洩氣太重。支行印綬之鄉為最美，比劫幫身亦佳".
- 論傷官取運 "傷官用財，財旺身輕，則利印比；身強財淺，則喜財運".
- 論財 "財旺生官者，身強…貴格也", 論行運 "財生官而身輕，而運助身".
- 論偏官 "煞旺食強而身健，極為貴格", "煞重身輕，用食則身不能當，不若轉而就印".
- 고전은 신약이어도 구조(局)는 인정하되 일간이 감당하지 못한다고 본다. 현대 한국 자료는 '신약·무근이면 미성립'과 '식상이 보호되면 신약도 가능'으로 갈린다(블로그·커뮤니티 수준).

### 7-2. 규칙(`pattern_conditions.DM_SPENDING_IDS`·`FRAIL_BANDS`)

대상 = 일간이 힘을 쓰는 구조 8종(식신생재·상관생재·식상생재·재생관·식신제살·상관제살·관살유제·살중용식). 약한 원국 = 신약·태신약(중화신약 제외). 재생살(신약이 본래 자리)·재관인상생(인성이 일간을 생하며 끝나는 순환)·충돌 구조(상관견관·재극인·탐재괴인·편인도식)는 대상이 아니다.
1. **운에서 신규 성립 금지**: 약한 원국에서는 8종을 운에서 '신규 성립'으로 내지 않는다(`_natal_prereq`). 그 운은 재다신약·설기태과·관다신약 줄이 설명한다. 살중용식은 원국 전제가 관다신약이라 운 신규가 없어지고 원국 성립분만 남는다.
2. **일간 쪽 글자 손실 ≠ 차단자 해소**: 약한 원국에서 비겁·인성 글자가 합·충·化로 덜어진 것은 생극·제어 구조(T1·T2)의 '차단자를 덜어냄' 기여가 아니다(`_contributes(frail=True)`). 억부(T3)·수화(T4)는 대상이 아니다 — 일간 쪽 손실이 곧 그 구조의 재료다(재다신약은 일간 측이 깎이면 서는 것이 맞다).
3. **원국 성립분 표지 상시(가안)**: 약한 원국에 8종이 성립하면 원국 줄 근거에 "신약형 — 일간이 약해 감당이 부족(비겁·인성 운에서 쓸 힘이 생김)"(`DetectedPattern.basis_note` — 화면 줄 끝·`llm_line` `[근거: …]`), 운 상태에는 표지 `weak_dm`. 조건부 `burden` 과 겹치면 `weak_dm` 하나만 둔다. 시주 미상 명식에는 근거 줄을 붙이지 않는다(신강약 미확정 — HOUR_UNKNOWN_POLICY).
4. **幫身 운(가안)**: 약한 원국에 성립한 8종은, 그 층의 운 글자가 비겁·인성만 공급하고 패턴의 다리 그룹이 손상(`damaged_groups` — 그룹 단위 절반 이상)되지 않았으면 직전 층 상태를 잇고(해소·완화 없음) 표지 `supported`("비겁·인성이 일간을 받쳐 감당할 힘이 생김")를 단다(`_is_support_layer`).
