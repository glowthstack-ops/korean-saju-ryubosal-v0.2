# 합(合) 상호작용 규격 — 룰엔진 결정표 (HAP_INTERACTION_SPEC)

> 목적: 만세 엔진이 "합(合)"을 **성립 → 작용 모드 → 영향 → 우선순위**로 판정하도록, 명리
> 이론을 소프트웨어 결정표로 정리한다. 현재 엔진은 합 성립 + `transform_element`(化神 후보)만
> 기록하고 **합화/합거/합반/합래/쟁투를 구분하지 않는다**(이 문서가 그 공백을 채우는 규격).

## 0. 출처·신뢰 등급·정책

**출처**: 子平真詮(자평진전·沈孝瞻), 滴天髓闡微(적천수천미·任鐵樵 注), 三命通會 등 1차 고전 +
현대 주류 자평/한국 명리. 2회 딥리서치 다출처 교차검증(2026-06-15).

**신뢰 등급 태그**:
- `[확정]` 1차 고전 + 다출처 교차검증(만장일치/우세).
- `[다수설]` / `[소수설]` 학파 갈림 — 다수설 채택, 소수설 병기.
- `[미검증]` 출처는 있으나 적대검증 미통과(세션 한도) 또는 정량 근거 약함 — **전문가 감수 대상**.
- `[기각]` 적대검증에서 부정(0-2/0-3) — 결정표에 넣지 않음.

**구현 정책(사용자 확정 2026-06-15)**:
1. **化(합화) 판정 = 3단계 확률화** — `confirmed`(확정 화) / `conditional`(가화·합반 경향) /
   `none`(불화). 단정하지 않고 confidence로 LLM에 조건부 전달.
2. **일간(日干) 합 = 합거×·기반×** (통설). 일간 자합은 合去로 치지 않고 해당 십성 그대로 사용,
   일간 자체는 합으로 묶이지 않음. (예외: 化氣格 성립 시 별도 — 후속 과제.)
3. **다수설 우선**, 소수설·쟁점은 표기하고 단정 금지(절대원칙 3·10).

## A. 합 성립 타입 카탈로그 `[확정]`

| 분류 | 구성 | 化神(결과 오행) | 비고 |
|---|---|---|---|
| 천간합 5 | 甲己·乙庚·丙辛·丁壬·戊癸 | 土·金·水·木·火 | 상생 순서 도출(子平真詮) |
| 지지 육합 6 | 子丑·寅亥·卯戌·辰酉·巳申·午未 | 土·木·火·金·水·火 | 午未化火=`[다수설]`, 化土=`[소수설]` |
| 삼합 4국 | 亥卯未·寅午戌·巳酉丑·申子辰 | 木·火·金·水 | 生(장생)-旺(제왕)-庫(묘) 구조 |
| 방합 4 | 寅卯辰·巳午未·申酉戌·亥子丑 | 木·火·金·水 | **강화**(변화 아님), 방위·계절 |
| 암합 | 천간↔지장간 / 지지↔지지 | — | 보조(현 `amhap_luck.py` 유지) |

**반합(半合)** `[다수설]`: 삼합 3자 중 **왕지(子午卯酉) 포함 2자**라야 성립.
- 왕지+생지(亥卯·寅午·巳酉·申子) = 강 / 왕지+고지(卯未·午戌·酉丑·子辰) = 약.
- 왕지 빠진 생지+고지(申辰·寅戌 등) = `[기각]` 인접만으로는 불성립(가합, 합으로 미인정 학파 다수).

지지↔지지 = 子戌·丑寅·卯申·寅未·午亥 `[다수설]`(광의 보조합은 소수설).

## B. 합 성립 차단 규칙 (합이불합·合而不合) `[확정, 子平真詮 論十干合而不合]`

성립 자체를 막거나 약화하는 선행 게이트. **천간합에 적용**(지지합 거리 효과는 `[미검증]`).

| 규칙 | 판정 | 효과 |
|---|---|---|
| **격위(隔位)** | 합하는 두 천간이 비인접(예: 年干↔時干) | 합 불성립 또는 효과 2~3할로 약화 |
| **간격 극(剋)** | 두 천간 사이에 둘을 극하는 천간 개입(甲己 사이 庚) | 합 불성립(넘어 합 못함) |
| **쟁합·투합(2:1)** | 한 글자에 둘이 합(両辛合丙·両丁合壬) | 情不專 → 합력 약화·불안정. 단 둘 중 하나가 隔位면 쟁투 소멸 |

> 거리 정량화("隔位太远=2~3할", "지지 인접도 감쇠율")는 고전 근거가 약하다 `[미검증·실무관행]`.
> 천간 거리 효과만 `[확정]`(KCI 학술 + 子平真詮), 지지 거리는 절충안 수준.

## C. 작용 모드 — 판정과 영향 (핵심)

같은 두 글자가 상황에 따라 다른 모드로 작용한다. 성립(B 통과) 후 아래로 분기한다.

### C-1. 化(합화) 3단계 확률화 `[확정 원리 + 정책]`

`transform_tier ∈ {confirmed, conditional, none}` — 아래 요소로 등급 산정:

| 요소 | confirmed(확정 화) | conditional(가화/합반 경향) | none(불화) |
|---|---|---|---|
| 化神 월령 | 旺/相(월령 득령) | 휴(休) 또는 통근만 | 囚/死 |
| 化神 통근·투출 | 지지 통근 + 투출 | 일부 | 무근 |
| 인화신(引化) | 있음(辰 등 化神 생조 글자) | 약 | 없음 |
| 방해(충·극·쟁투) | 없음 | 일부 | 다(쟁투·충극) |

- **化 성공 시**: 명식을 化神 오행으로 본다("化得真者只论化" 滴天髓 化象). 化神 강약 보정 —
  旺하면 설기하는 오행을 用, 衰하면 생조하는 오행을 用 `[확정, 滴天髓]`.
- **인화신 辰(龍) 필수설은 `[소수·강조설]`(적대검증 0-2 기각)** → 化神 생조 요소의 *하나*로만
  가중, 필수 조건으로 하드코딩하지 않는다.
- 戊己土 과다 → 쟁투, 甲乙 과다 → 강약 성질 변동으로 化 저해 `[확정, 滴天髓 化象]`.

### C-2. 합반(合而不化·合絆) `[확정]`
化 등급 `none`이면서 합은 성립 → 두 글자가 **억지로 묶여(勉强)** 본래 작용이 **정지·반감**.
"必非佳偶"(滴天髓). 점수: 묶인 두 글자(십성/오행)의 기여를 감산(정량은 정책 가중).

### C-3. 합거(合去) `[확정, 子平真詮·滴天髓 合局]`
한 글자가 합으로 끌려가 그 **십성 작용이 사라짐**(투출해도 불투 효과, "夫星透而不透").
- **방향성 = 위치(선합·인접)**: 일간 아닌 다른 천간이 대상을 **먼저** 합해가면 합거.
  (庚 年干, 乙 月干 → 월간 乙이 먼저 庚과 합 → 일간은 합 못함 = 庚 합거)
- **길흉(영향)**: `喜神(용·희신) 합거 = 흉`(기능 무력, 合而无用) / `忌神(기·구신) 합거 = 길`
  (흉 해소, "煞不攻身"). 원리: "逢吉不为吉, 逢凶不为凶". `[확정, 3-0]`
- **일간 자합은 합거 아님**(정책 2) — 일간이 자기 官/財를 합하면 그 십성 그대로 사용. `[확정, 3-0]`
- **십성 특칭** `[확정, 子平真詮 論正官·論偏官 3-0]`:
  - **거살유관(去殺留官)·거관유살(去官留殺)**: 관살혼잡에서 칠살(또는 정관)을 합거해 명식을 맑힘 → 길.
  - **탐합망관(貪合忘官)**: 정관이 합에 빠져 관 본연의 작용(貴)을 잃음 → 흉.
  - 단 **"합거=무조건 길"은 `[기각, 1-2]`** — 무엇이 합거되는가(희/기신·관/살)에 따라 다름.
- **거류(合去) 강도 = 조건부(非 boolean)** `[확정, 三命通會 卷5 3-0]`: 투출(드러난) 십성 합거는
  쉽고, **암장(지장간) 십성 합거는 어렵다**; 합거 주체가 다수·유력해야 성립. (Phase 1은 투출
  천간만 — 암장·세력 정련은 §G 후속.)

### C-4. 합래(合來) `[확정, 滴天髓 合局]`
합거(보냄)의 대칭 — 합이 글자/십성을 **데려옴**(특히 운에서 유입). 방향으로 길흉 판정:
- `喜神 合而來 = 길` / `忌神 合而不去 = 실패` / `喜神 合而不來 = 미흡`.
- 운(대운·세운·월운) 글자가 합으로 원국에 약하던 십성을 끌어와 그 시기 사건화.

### C-5. 쟁합·투합 `[확정]`
2:1 경합 → 情不專, 합력 약화·불안정, **化 통일 어려움**(분합·쟁합 시 化 저해). 隔位면 소멸(B).

## D. 우선순위·상호작용 결정 규칙

### D-1. 합 vs 충/극 `[확정, 滴天髓 合局]`
- **합이 충보다 우세**: "冲得合而静则易, 合得冲而明则难" — 합이 충을 잠재우기는 쉬우나 충이
  합을 깨기는 어렵다(**탐합망충 貪合忘沖**). 단 **기신 합이면 오히려 더 흉**("忌合而合之, 比冲愈凶").
- **탐합망극(貪合忘剋)**: 합이 극을 잊게 함 — 기신/칠살이 합되면 일간을 공격 못함(흉 해소).
- 합·충 동시 = "상호 상쇄(둘 다 풀림)" 다수설은 `[기각]`(0-3) → **합 우세로 처리**.
- `合多不沖`(합 다수 시 충 불성립) = `[미검증]` 정량 기준 불명.

### D-2. 합과 형/파/해 동시 성립 `[확정/다수]`
같은 지지쌍이 합이자 형·파·해인 경우:

| 지지쌍 | 동시 성립 | 처리(다수설) |
|---|---|---|
| 巳申 | 육합(化水) + 삼형(寅巳申) | 합·형 병존 — 합 우선이나 형의 불안정 잔존 |
| 寅亥 | 육합(化木) + 육파 | 합 우선, 파로 합력 약화 |
| 寅巳 | 삼형 + 육해 | 형+해 가중 |
| 申巳 | 삼형 + 육파 | 형+파 가중 |

- 육해 6쌍: 子未·丑午·寅巳·卯辰·申亥·酉戌. 육파 6쌍: 子酉·丑辰·寅亥·午卯·申巳·戌未.
- `[소수설]` 육해가 육합을 깬다 / 파가 삼합을 깬다 — 병기하되 다수설(합 우선·약화)로 기본.

### D-3. 원국 합 vs 운(運) 합 동역학 `[다수설]`
운 글자가 들어와:
1. **원국에 없던 합 성립**(합래·합거 발동 — 운에서 자주 발생).
2. **충개합(沖開合)**: 원국 합을 운의 충이 풀어 묶였던 글자 해방.
3. **합해충(合解沖)**: 원국 충을 운의 합이 막아 정지.
- 원국 합(상시) vs 행운 합(해당 운 기간 한정·일시): 작용 **강도·지속성 차이**(원국>행운).

### D-4. 합력 강도 위계 `[기각 → 학파 파라미터로 외부화]`
- **통일 정량 위계는 고전 근거 없음** — "三會(방합)>삼합>육합>반합" + 정량 비율(三會=6×육합·2×삼합),
  "三會 우선" 충 우선순위는 모두 `[기각, 0-3]`. 학파마다 삼합>방합/방합>삼합이 갈린다.
- 유일하게 우세한 정성 위계 `[다수, 정량 근거 없음]`: **삼합 > 왕지+생지 반합 > 왕지+고지 반합 > 가합**
  (왕지 유무가 강도 좌우).
- **결론**: 강도 위계·감쇠율을 엔진에 **하드코딩 금지**. **학파 설정 파라미터(가중치 테이블)로 외부화**
  하고 캘리브레이션으로 조정한다(§G).
- 합·충 견고성 세부("삼합은 충에 안 깨진다", "合解冲", "合冲为先" 우선순위)도 `[기각/소수, 0-3]` —
  다수설(D-1 합>충 일반)만 채택, 세부는 단정 금지.

## F. 엔진 구현 매핑 (다음 단계 — 별도 승인)

### F-1. 데이터 모델 (`relations.py` Relation 확장)
```
hap_mode: "combine"|"transform"|"bind"|"remove"|"attract"|"contend"
          (합/합화/합반/합거/합래/쟁투)
transform_tier: "confirmed"|"conditional"|"none"   # C-1 3단계
transform_element: str|None                         # 化神(기존)
direction: "away"|"toward"|None                     # 합거/합래
affected_god: str|None       # 합거·합반된 십성(영향 대상)
favorable_effect: "boon"|"harm"|"neutral"           # 용기신 결합 길흉
blocked: bool                # B 차단(합이불합)
contend: bool                # 쟁합/투합
co_relations: list[str]      # D-2 동시 형/파/해
luck_origin: bool            # D-3 운 유입 여부
```

### F-2. 판정 파이프라인 (순서)
1. 성립 후보 탐지(기존 interactions) → 2. **B 차단 게이트**(隔位·간격극·쟁투) →
3. **C-1 化 등급 산정**(월령·통근·인화·방해) → 4. tier에 따라 모드 분기(化/합반) →
5. **C-3/C-4 합거·합래 방향**(위치·운유입) + 용기신 길흉 → 6. **D 우선순위**(합>충, 합형파 병존) →
7. 점수 가중(합거 기신=+, 희신=−; 합반=감산; 합화=化神 역할로 전환).

### F-3. 사전·그래프
- `relations.json`/그래프 combination 노드의 `possibleModes`(이미 존재) → **resolved mode**와 연결,
  `reviewed:true`로 모드별 trigger·해석힌트·금기 정비.
