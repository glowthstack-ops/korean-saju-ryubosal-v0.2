# 10. 풀이 상품 설계 (총운 / 한해풀이 / 집중 / 대화형)

> **이 문서의 목차·섹션 구성·페르소나 정의는 예시가 아니라 전체 규격이다.**
> Claude Code는 섹션을 임의로 추가·삭제·병합·순서변경하지 않는다. 분량·구성 변경은 사용자 승인 필요.

## 1. 상품 정의

| 상품 | 코드 | 분량 | 생성 방식 | 갱신 |
|---|---|---|---|---|
| 총운 풀이 | `RPT_FULL` | A4 약 28~40장 (고정 25섹션 39,000~48,000자 + 십년 풀이 페이지 5~10장) | 섹션별 LLM 생성 → 조립 (비동기 작업) | 1회성 + 대운 교체 시 재구매 갱신 |
| 한해풀이 | `RPT_YEAR` | A4 약 11~14장 (본문 약 17,000~22,000자) | 섹션별 LLM 생성 → 조립 | 년도당 1회성 |
| 주제별 집중 풀이 | `RPT_FOCUS` | A4 약 8~9장 (본문 약 12,000~14,000자) | 섹션별 LLM 생성 → 조립 | 주제×기간당 1회성 |
| 대화형 풀이 | `CHAT` | 턴당 응답 | docs/03 오케스트레이터 실시간 | 상시 |

> **분량 캘리브레이션(2026-06-14 사용자 확정 'B').** 각 목차표의 `분량(자)` 컬럼은 **편집 의도값**이며,
> 실제 분량 검사는 `report_plan.calibrate_chars()`가 이를 LLM 실측 밴드로 압축한 값으로 한다. 측정 결과
> gemini-3-flash는 목표 크기와 무관하게 섹션당 ~1,400~1,950자에 수렴(목표 4,500~5,500자 섹션도
> ~1,700~1,950자)하므로, 길게 잡은 목표를 일괄 유지하면 분량 검사(무허용오차)가 항상 실패한다.
> 캘리브레이션 밴드: 짧은 섹션(의도 mid<2,200) → 700~2,200자, 표준·긴 섹션 → 900~2,900자.
> 위 표의 A4 장수는 캘리브레이션 후 실측 기준이다.

세 상품은 **동일한 사전계산 저장소(docs/09)와 Topic Builder를 공유**한다. 보고서는 "대화형 파이프라인을 섹션 수만큼 정해진 순서로 실행해 묶은 것"이며, 별도 분석 로직을 만들지 않는다.

## 2. 공통 생성 파이프라인 (보고서형)

```
ReportSpec (상품/대상/기간/주제/페르소나)
  → SectionPlan[] 생성 (3·4장의 고정 목차 → 섹션별 모듈·기간·분량 확정)
  → 섹션별: Topic Builder 실행 → SectionContextBundle (docs/06 계약 + 분량 목표)
  → 섹션별 LLM 호출 (의존성 없는 섹션은 병렬 허용, 최대 동시 4)
  → 결정적 정합성 검사 (7장) — 실패 섹션만 재생성 (최대 2회)
  → 조립: 표지/목차/페이지 → docx + pdf (스킬 파이프라인 사용)
  → 산출물 저장 + 사용자 알림
```

```typescript
interface ReportSpec {
  productCode: 'RPT_FULL' | 'RPT_FOCUS';
  subjects: SubjectRef[];               // FOCUS는 동반자·궁합 주제 가능
  topic?: Domain | 'compatibility';     // FOCUS 전용
  period: { start: string; end: string };
  personaId: string;                    // 6장
  language: 'ko';
}

interface SectionPlan {
  sectionId: string;                    // 'F-07'
  title: string;
  moduleCalls: { moduleId: string; params: object }[];   // M01~M15
  targetChars: { min: number; max: number };
  dependsOn: string[];                  // 정합성 위해 선행 필요한 섹션 (예: 용신 확정 섹션)
}
```

### 3-1. 생애 변곡점 연표 (F-14) 규격

- **창**: 출생~90세 (`spec.period` = `lifetimePeriod`와 일치). 90세 이후는 "풀이는 90세까지를
  기준으로 본다" 한 줄 안내로 종결.
- **데이터**: 전 생애 세운 연 단위 재채점 — 채팅 lifetime scan(`daewoon_table[i].sewoon` 재사용
  + 첫 대운 이전 유년 보충)을 공용 엔진으로 승격해 리포트·채팅이 같은 산출을 쓴다. 즉석
  재계산 신설 금지(사전계산 원칙 — 기존 T0/T1 산출 재사용만 허용).
- **선별**: 연도 최고점순 → 의미 클러스터 중복 압축(overview 클러스터 키 재사용:
  event_key+길흉 방향+지배 신호 계열) → 10년 구간당 최대 3개 → **총 20개 상한**.
  품질 게이트: 후보 존재 연도만, 무신호 강제 충원 금지(빈 구간은 그대로 둔다).
- **표기**: 각 변곡점에 도메인 라벨 6종(이동/직업/재물/관계·결혼/건강/육친) + 길흉 방향 + 나이.
- **서술 계약**: 과거 연도=회고·적중 확인 유도(단정 금지), 미래 연도=Activation Window
  (가능성·기류), 표 밖 연도 '신호 없음' 단정 금지, **월별 상세는 변곡 연도당 최대 1~2개 달만**.
- 기존 근접 5년 연도 스펙트럼 표(`year_spectrum_lines`)는 "근접 5년 상세부" 보조로 계속 부착
  — 생애 연표가 골격, 스펙트럼 표는 가까운 몇 해의 해상도 보강.

**십년 풀이 하위 페이지 (F-14-D\*, 2026-08-13 사용자 제안 '10년 단위 페이지 분리' 채택)**:
F-14(연표 개관) 뒤에 **현재 대운부터 90세 창 끝까지 대운당 1페이지**를 동적으로 생성한다
(페이지 수=잔여 대운 수, 통상 5~10 — 고정 목차의 유일한 동적 확장이며 확장 규칙 자체가 규격).
- 페이지 입력 = 그 대운 10년의 세운 **전 연도**(간지·운 품질 등급·대표 사건 — `year_spectrum_lines`
  재사용, 전 생애 병합 결과+생애 후보 풀) + 그 대운 정보(십성·현재/지남/예정 마커).
- 서술 계약: 그 10년만, 각 해를 빠짐없이 1~3문장(★주목 해는 상세), 과거=회고·적중 확인,
  미래=활성화 창. 다른 대운·연도 사건 인용 금지, 근접 5년 반복 금지.
- 분량 900~2,900자/페이지. LLM 호출 = 25 + 잔여 대운 수. `FULL_TOTAL_TARGET`(48,000자)은
  고정 25섹션 기준이며 십년 페이지 분량은 별도 가산.
- 근접 5년 스펙트럼·전역 top 후보는 십년 페이지에 부착하지 않는다(같은 5년 반복 결함 차단).

**도메인 섹션 생애 연동(전면)**: F-15/F-16/F-17/F-17c(출산 신호 한정)/F-18/F-18b는 생애
후보 풀에서 **자기 도메인 행을 직접 선별**(최대 5행, 10년 구간당 2·클러스터 캡 2)해 근접
5년 밖 장기 흐름을 함께 서술한다 — 전 섹션이 오늘~+5년만 반복하는 것을 금지.

### 3-2. 조직 규모 적합 (F-15) — 서술 전용 매핑

점수·날짜·판정에 관여하지 않는 **서술 전용** 매핑이다(페르소나 원칙과 동일한 위상). 이 표가
SSOT이며 구현은 서술 디렉티브(코드 상수), 어휘가 커지면 사전(JSON) 승격.

| 구조 신호 (M03/E5 산출) | 어울리는 조직 결 | 축 (조직 구조·소통·규모) |
|---|---|---|
| 정관·정인 중심 (규범 수용·위계 적응·안정 지향) | 대기업·공공 | 체계적 분업, 공식 소통, 프로세스·안정 |
| 식상 발달 + 비겁 자립 (자율·창의·수평 소통) | 스타트업·소규모 | 빠른 의사결정, 역할 유동, 불확실성 내성 |
| 재성 실무 + 식신 지속 (실리·성과 가시성·관계 밀착) | 중견·중소 | 넓은 전결 범위, 대표와 직접 소통, 성과 체감 |
| 편관·양인 (경쟁 내성·압박 돌파) | 경쟁 강도 높은 조직·영업 중심 | 성과 압박, 속도 |
| 인성 과다 (숙고·전문성 축적) | 연구·전문직형 (규모 무관) | 전문성 중심 평가 |

- 보조축: 신약+인성 의지 → 체계 지원이 있는 큰 조직이 소모가 적다 / 신강+식상 → 자기
  주도형 작은 조직이 결이 맞다.
- 2단계 프로필 직업 입력 시 현 직장 규모를 감안해 서술, 미입력이면 일반 서술(원칙 11 —
  기능 차단 금지).
- 표현 수위: "어느 쪽이 맞다/틀리다"가 아니라 "결이 맞는 / 소모가 큰" — 단정 금지 규칙 동일.

### 3-3. 미혼 배우자상 (F-17)

- **대상**: 프로필 결혼 상태가 미혼 또는 미입력. 기혼 입력 시 배우자상 대신 배우자 관계
  흐름 서술로 대체.
- 원국 배우자궁(일지)·배우자성(재/관)·조합 물상 기반으로 **외모 인상·성격·성향을 적극
  서술한다**(2026-08-13 사용자 확정 — 재미요소). 인상·체형 결·스타일·분위기까지 허용,
  구체 수치(키 몇 cm 등)·확정 단정만 금지. 서두 또는 말미에 "재미로 보는 겉모습" 단서 1회.
- **이원 정책**: 실존 상대(궁합 RP-03)의 외모 추측 금지는 기존 그대로 유지. 이 절은
  원국에서 그리는 가상의 배우자상에만 적용된다.

### 3-4. 육친 서술 정책 (F-17b/F-17c) + 이사 (F-18b)

- **부모(F-17b)**: 인성(육친 부모) 동요 신호 기반 건강 주의 시기·관계 돌봄 시기 서술.

## 4-2. RPT_YEAR 한해풀이 — 전체 목차 (규격, 12섹션)

**강신호 반복·intent 편향 방지(2026-06-16 사용자 확정 — RPT_YEAR·RPT_FULL 공통)**: 종전엔 전 섹션이 같은 전역 top-8 후보를 공유해 한두 강신호(예: 특정 달의 큰 이동수)가 모든 섹션에 반복됐다. 이를 막기 위해 ① **섹션별 도메인 후보**: 도메인 섹션(Y-06 직업/Y-07 재물/Y-08 관계/Y-09 건강 · 총운 F-15~F-18b — F-17b 육친-부모/F-17c 육친-자녀/F-18b 이동 포함)은 자기 도메인 후보만(`domain_candidates`, 길·흉 모두 포함, 주의운 최대 2건 보장) 본다. ② **12개월 전체 표**: 월별 흐름(Y-05)은 `month_overview_lines`로 12개월을 빠짐없이(간지·우세 도메인·강도밴드·길흉·★주목 Top3) 제공해 모든 달을 고르게 다룬다. ③ 프레이밍에서 좋은 운·주의운을 함께, 각 운의 **활용·대비 방향**을 곁들이도록 지시.

**전 구간 스펙트럼 확대(2026-06-23 사용자 확정 — 테마 FOCUS·RPT_FULL 보강)**: 위 장치를 테마 전용 FOCUS(W/J/R/RL)와 총운으로 확장한다(목차 섹션 가감 없이 데이터·풀이 프로세스만). ① **다년 월운 생성**: `calculate(reference_date)`는 기준일 근방 12개월만 채우므로, 보고서는 예측 창(오늘~+5년) 각 해의 월운(`luck_months`)을 주입해 월 단위 후보·12개월 표가 다년에 걸치게 한다(종전 1년치만 존재 → '특정 달 반복'). ② **연도 스펙트럼 표(`year_spectrum_lines`)**: '향후 N년 종합' 섹션(W-06/J-05/R-05/RP-06/RL-06·generic C-03)과 총운 생애 변곡점 연표(F-14, 근접 5년 상세부 보조 — 3-1절)에, 예측 창 세운을 해마다 빠짐없이(운 품질 등급·우세 도메인·강도밴드·길흉·★주목) 제공한다. ③ **월 표 다년 그룹화**: `month_overview_lines`를 〈연도〉별 그룹으로 출력하고, 테마 '주목할 달' 섹션(W-07/J-06/R-06/RP-07/RL-06·generic C-04)에 부착한다. ④ **도메인 인지**: 스펙트럼 표·후보는 그 섹션 도메인의 사건을 대표로 쓰되 운 품질 등급(좋은/주의/평범 해·달 1차 기준)은 도메인 무관 표기한다(Y-05는 도메인 비지정 → 교차도메인 유지). ⑤ 스펙트럼 섹션은 검사 상한을 넓힌다(`_WIDE_SECTIONS`, 하한은 캘리브레이션값 유지).

## 6. 페르소나 시스템

**고정 프리셋(구버전 P1~P3)은 폐지되었다.** 페르소나는 사용자가 5축을 조합해 설정한다 — 전체 규격은 `docs/11_USER_PROFILE_ONBOARDING.md` 5장:

```
counselorGender (female/male/neutral) × counselorAgeBand (20s~60s+)
× speech (존대/반말 × 해요체/합쇼체/하게체/반말체 — 유효 조합 제한)
× difficulty (easy/standard/expert)
× userHonorific (프리셋 7종 + custom)
```

본 문서에 남는 불변 규칙 (페르소나보다 우선):
1. 단정 금지 표현 세트, windfall/건강/투자 고지 문구, 미성년 보호 톤(docs/08 G2)은 어떤 페르소나에서도 동일 적용.

3. 보고서(RPT_*)는 생성 시점의 PersonaConfig를 스냅샷으로 고정 — 생성 도중 변경돼도 해당 보고서 내 문체 일관 유지.
4. 일회성 어투 요청("동화처럼")은 PersonaConfig를 바꾸지 않고 OutputStyle.toneOverride로만 처리.
