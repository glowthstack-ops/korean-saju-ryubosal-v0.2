# 16. 답변 시간 지평(Horizon) 정책

> 2026-07-09 데굴님 피드백: "질문에 대해 너무 장기적인 부분을 설명하려는 경향이 있다."
> 시점 없는 미래 질문이 전부 10년 연 단위 digest(vague_future)로 빠지던 것을, 질문
> 유형별 지평으로 제한한다. docs/03 B3·docs/08 C1의 "분야별 기본 기간" 설계(구현돼
> 있었으나 미소비 — `rewriter.DEFAULT_PERIOD_MONTHS`)를 이 정책이 소비한다.

## 1. 정책 표 (2026-07-09 확정)

| 유형 | 감지(규칙 기반) | 지평 |
|---|---|---|
| **즉시형** | 지금·당장·급~·빨리·이번 달/주 | **향후 3개월 월 단위** |
| **시도·전망형** | 해볼까·해도 될까·성공할~·될까·어떨까·도전 | **앞 6개월 월 단위 + 5년 연 단위** |
| **구조 결정형** | 사업·창업·폐업·퇴사·그만두~·이혼·전업·이민·귀농·독립 | **원국 적합성 + 현재 대운 배경 + 5년 연 단위 + 당장 3개월** |
| **분야 기본** | 위 신호 없음(무시점 분야 질문) | `DEFAULT_PERIOD_MONTHS` (재물·직업·건강·학업 12·연애·이사 6·일반 3개월) 월 단위 |

우선순위: 면제(§2) > 구조 결정 > 즉시 > 시도·전망 > 분야 기본.

공통 규칙: **지평 밖 연·월은 본문 서술 금지**(제공 자료에 있어도 무시). 답변 끝에
"더 긴 흐름이 궁금하면 이어서 물어보라" **한 줄 안내만 허용**(그 한 줄에 구체
연도·간지·길흉 금지). 컨텍스트도 함께 제한 — 후보·표·대운 배경이 지평 창 안으로만.

## 2. 정책 면제 (기존 결정·경로 보존)

- **명시적 장기 질문**(대운·인생 흐름·평생·노후·10년): 기존 10년 digest + 연도 지정
  유도 유지.
- **개방형 '언제' 질문**(언제·어느 해·때를·시기·타이밍): 기존 10년 digest 유지 —
  2026-06-18 확정(12개월로 좁혀 특정 달 단정하던 결함의 보완책) 보존.
- 명시 시점(연·월·기간)·과거 회고·CHART_ANALYSIS(구조)·택일·기간총운·목적지 확정
  이사: 기존 경로 그대로(정책 미개입).

## 3. 구현

| 구성 | 위치 |
|---|---|
| 정책 산출 | `saju_engines/horizon.py` — `resolve_horizon(question, intent) → HorizonPolicy \| None`, `horizon_directive`, `month_add` |
| 배선 | `chat_service.chat()` — vague_future에서 정책 해석: `default_period`(후보 창), 결합 표(앞 N개월 월 단위 + 연 단위, `[운 흐름 요약]` 헤더), `[대운 배경 — N년 흐름]`(연 span 있을 때만), `[답변 지평]` 디렉티브(10년 digest 지시 대체) |
| 대운 프레이밍 | 구조 결정형(natal_fit)·명시 장기에만 부착 — 즉시·전망형에 붙이면 다시 장기 서술로 흐름 |
| 표 헤더 | `context_reducer` 월·연 혼합 표는 `[운 흐름 요약 — 앞 N개월 월 단위, 이후 M개년 연 단위]` |
| 회귀 테스트 | `tests/unit/test_answer_horizon.py` — 기준 예시 4질문 + 장기 유지 + 한 줄 안내 |

기준 예시(회귀 고정): ① "지금 돈이 좀 필요한데 돈이 생길 여지가 있을까?" → 3개월
② "사이드프로젝트로 부업을 해볼까 하는데 성공할 수 있을까?" → 6개월+5년
③ "아예 사업을 시작해보는 건 어떨까?" ④ "지금 회사는 그만두면 안돼?" →
원국 적합성+현재 대운+5년+3개월. 감지는 규칙 기반이며 LLM 판정 금지(절대원칙 1).
