## 2. 편인 도식 강의

| 강의 | 엔진 | 처리 |
|---|---|---|
| 도식 = 원국 식신 + 운 편인, 식신이 많고 강하면 도식이 깊지 않고 하나일 때 정확히 작용 | 구조 패턴·운 스택 조합만, 원국 식신 × 운 편인 없음 | 원국 식신 1개 / 2개 이상 분기 문구 |
| 경제 활동 제약(같은 일에 소득 덜·노력 1.5~2배) | 편인 운 문구 '경제 활동의 발목' | 도식 문구에 포함 |
| 조심성 상실(더듬이) — 건물 매입·사업 확장·동업은 앞선 사람·전문가 조언 | 없음 | 도식 문구 핵심 |
| 편인의 속뜻 = 일에 빠진 식신을 쉬게 함 | 편인 운 '쉬어가는 운' | 동등 |
| 식신 중독(긍정: 전문가 / 부정: 도박·알코올·마약) | 없음 | 데굴님 결정: **상담(카운슬링)으로 넣는다** — 식신 2개 이상일 때 가능성형·자기 점검 권유, 진단·단정 금지 |
