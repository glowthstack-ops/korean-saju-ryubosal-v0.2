# C5 — 건강·사고 채널 분석과 제안 (2026-10-07)

상태: **분석 완료 — 결정 대기**(엔진 미수정). 상위: `CASEBOOK_CALIBRATION_PLAN.md` §4 C5.
정책 전제(절대원칙 3): 질병명·사망·수명 단정 출력 금지. 사망·요절 사례는 내부 평가 축으로만 쓴다.

## 1. 지금 건강 신호가 나오는 세 경로와 상태

| 경로 | 생성 방식 | 사례집 11건(12연도)에서의 상태 |

## 2. 제안

**C5-1 (배선, 새 규칙 없음)**: `health_risk_windows` 점수를 건강 채널의 단일 원천(SSOT)으로 삼는다.
- 이벤트 엔진의 `health_attention` 후보 점수를 health.json 7규칙 대신 창 점수에서 파생(창 점수 ≥ 임계일 때만 후보 생성,
  favorability는 기존 용기신 품질 매트릭스 유지, polarity는 '주의/관리').
- 생애 연표(lifetime_scan)·채팅 "언제 건강" 질문·casebook 지표(`DOMAIN_EVENTS["health"]`)가 같은 점수를 본다.
- health.json 7규칙은 '보조 근거 문구'로만 남기고 점수 생성에서 뺀다(중복 가산 금지).

**C5-2 (노출 임계 — 개인 분위수)**: 전역 임계 ≥30은 생애의 34%를 '관리 권장'으로 만든다(과다 경고). 노출은 **본인 생애
분포의 상위 15%(p85)** 이상으로 하고, 강도 라벨도 분위수로(p85 생활 관리 · p93 정기 검진 · p97 적극 관리). 절대 점수는
내부 보관. 12연도 적중은 p85 기준으로 재측정해 보고한다(지금 자료로는 ≥30=58%·≥50=17%라 중간 임계가 적정).

**C5-3 (위험 shadow 정규화)**: HLT_* 는 incident_risk가 없으므로 "위험 밀도" 지표에서 health 도메인은 **pressure 수를 개인
기준선 z-score**로 바꾼다(계획서 C5-a). 노출 로직(expose)은 건드리지 않는다.

**C5-4 (정책)**: 사망·요절·자살 사례(036/L·039/R·044/R·057/R)는 평가 지표에만 쓰고, 어떤 경로도 "사망" 어휘를 생성하지
않음을 `prohibitedClaims`·프롬프트 지시문에서 재확인한다(현 HLT 규칙에 "질병명 단정" 금지가 있음). 사고(accident) 전용
이벤트 키 신설은 **하지 않는다** — HLT `accident_injury` 14규칙과 창 점수로 충분하고, 키를 늘리면 LLM 입력 계약(docs/06)
변경이 따른다.

**보류**: 오행-장부 사전 확장(`health_element_organs.json` 보강, 047 火=심장·土=위장 류)은 사전 감수 항목으로 큐에 올린다.
036/L 1971(세운 용신운인데 사망)처럼 억부 극성과 정반대인 사례는 C2 보류 항목(규칙 B·축 공식)과 함께 다룬다.

## 3. 영향 범위(C5-1·2 적용 시)

- 변경 파일: `event_engine_v2.py`(health_attention 후보 생성 분기), `lifetime_scan.py`(건강 창 병합), `structural_context.py`
  (분위수 노출), `casebook_report.py`(health 도메인 지표가 창 점수를 보게), 리포트 Y-09·F-18 문구는 불변.
- 기존 테스트: `test_structural_context`(관리 권장 시기 문구), `test_event_scoring_cases`(health_attention 기대가 있으면),
  risk shadow 밀도 스크립트. 기준 사주 6건·골든은 무관(용신·격국 불변).
- 지표: 사례집 health/accident/death 11건의 "도메인 이벤트 히트"가 2/11 → 7/12 수준으로 올라갈 것으로 예상(창 ≥30 기준),
  false positive(생애 34%)는 C5-2 분위수로 억제.

## 4. 결정 요청

1. C5-1 배선(건강 창 점수를 health_attention·생애 연표·채팅의 단일 원천으로) 승인 여부.
2. C5-2 노출 임계를 개인 분위수(p85/p93/p97)로 바꾸는 안 — 전역 ≥30 유지 대안과 택일.
3. C5-3 risk shadow health 도메인 z-score 정규화(지표 전용) 승인.
4. C5-4 사고 이벤트 키 신설 **안 함**·사망 어휘 금지 재확인에 동의하는지.
