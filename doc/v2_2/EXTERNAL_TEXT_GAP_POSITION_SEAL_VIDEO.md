# 외부 영상 대조 — 합격은 자리(관성)·자격(인성) 두 축 + 다른 주제로의 확장 (2026-11-20)

> 데굴님 요청: "취업, 자격, 공모 등과 관련해 다음과 같은 영상 스크립트를 참고해서 개선해보고자 해" → 결정 "제안대로 진행해. 그리고 비슷한 형태의 풀이로 다른 intent에 대한 풀이를 고도화할 수 있는지를 검토해서 추가 진행해줘."
> 후속 결정(같은 날): "승진을 합격 기류 표지 대상에 넣고, 사업 렌즈를 리포트에도 싣자" · "출산은 생각외로 가능성 여부를 궁금해하는 부분이라 민감영역은 아니야." — §5·§6·§8에 반영.
> 출처 표기는 사용자 노출 문구에 쓰지 않는다(명리 게시물 대조 층 원칙).

## 1. 영상의 요지

1. 합격은 두 글자로 본다 — 관성(나를 부르는 자리·직책·평가)과 인성(공부·자격·문서로 그 자리를 받는 힘).
2. 같은 글자라도 천간으로 오면 소식·이름(발탁·명단), 지지로 오면 실제 자리(입사·발령)다. 인성은 천간이면 필기·자격 공부, 지지이면 임명장·계약서 같은 문서다.
3. 판 네 갈래
   - 원국에 관성이 한 글자도 없다가 운에서 들어온다 — 추천·제안처럼 낯선 모양, 평가대에 서는 부담.
   - 관성이 많은데 받쳐 줄 인성이 없다가 운에서 인성이 들어온다 — 누르던 힘이 자격·서류로 이어지는 다리(살인상생).
   - 대운에 인성이 놓여 있다 — 해마다 오르내려도 10년의 바닥이 공부를 받친다.
   - 관성·인성이 원국에 이미 이어져 있다(관인상생) — 운에서 관성이 한 번 더 오면 줄이 함께 움직인다. 줄이 길면 무겁다.
4. 조언 — 관성이 드는 때는 지켜보는 눈이 늘어 말·오타를 조심, 인성이 많아지면 생각이 늘고 손이 늦어져 마감부터 챙긴다. 대운이 바뀐 해나 바뀌기 직전 해는 결과가 크게 출렁이니 두 번 두드릴 일정.
5. 합격 글자는 해마다 차례가 돌아온다(다음에 그 글자가 드는 해).
6. 일간 오행별 일반론("쇠로 태어난 분은 8·9월에 힘") — 영상의 코너 1이 "이 판은 쇠가 이미 넘쳐서 그 두 달이 오히려 무겁다"로 스스로 뒤집는다.

## 2. 사실관계

- 영상의 간지·십성 대응은 엔진과 일치한다(2027 丁未 — 金 일간에 丁 = 관성·未 = 인성, 水 일간에 未 = 관성, 土 일간에 丁 = 인성).
- 코너 세 명식을 엔진으로 재현하면 영상의 읽기와 같은 사실이 나온다.
  - 辛酉 庚寅 辛酉 辛卯: 관성·인성 모두 드러난 글자 없음 → 2027 세운 천간 관성·지지 인성.
  - 己酉 丙子 壬戌 辛丑: 관인상생·살인상생 원국 성립, 2021~2031 庚午 대운 천간 인성, 2027 세운 지지 관성.
  - 癸酉 己未 甲寅 辛未: 2025~2035 癸亥 대운 천간·지지 인성, 2027 세운에는 관성·인성 없음 → 관성 2028·2029, 인성 2031·2032.
- 코너 풀이는 결과가 없는 상담이라 캘리브레이션 표본이 아니다.
- 실증: 2026-11-11 측정(`EXTERNAL_TEXT_GAP_EXAM_LUCK_POST.md` §4)에서 관성·인성 시기 표지는 실제 입사 달 포함률 58%로 우연 포함률 66%를 넘지 못했다. 시험 합격 확정 기록은 원장 1행이다. 이 영상의 시기 주장을 새로 검증할 표본은 없다.

## 4. 구현 — 축 글자 도래 층 (서술 전용)

- 모듈 `saju_engines.axis_arrival_lens`, 사전 `interpretations/axis_arrival_lens.json`(렌즈 5종, 전부 reviewed:false).
- 질문 주제마다 중심이 되는 십성군(축)을 정해 두고(렌즈), 그 군이 원국에 어떻게 놓였고 운의 어느 층·어느 자리로 오는지를 주제의 말로 옮긴다.
- 판정은 전부 기존 엔진 값이다. 새 임계·새 규칙은 없다.

  | 판정 | 출처 |
  |---|---|
  | 드러난 글자 없음(가시 글자 0)·많음(실세력 30% 이상)·역할 | `luck_structure_tags.natal_structure_profile` |
  | 이어지는 구조(관인상생·살인상생·재관인상생 / 식신생재·상관생재·식상생재) | 구조 패턴 원국 성립 |
  | 운 층·글자(대운 → 세운 → 월운, 지지는 본기 십성) | `hidden_latent_activation.luck_units` |
  | 대운 교체 전후 | 교운 방향 층과 같은 교운일·교운 가중(앞뒤 1년) |
  | 다음에 드는 해 | 달력 계산(`year_ganzi`) — 질문 기간 뒤 12년 안에서 군마다 2해 |

- 블록 구성: 머리말(주제의 두 축) → 원국 줄 → 운 층 줄(축 글자가 든 층만, 시점 순) → 뜻 줄 → 사용 규칙.
- 뜻 줄의 종류

  | 종류 | 조건 |
  |---|---|
  | 천간·지지 양상 | 세운·월운에 축 글자가 든 (군, 자리)마다 한 번. 대운은 10년 배경이라 사건의 모양을 말하지 않는다 |
  | 없던 것이 들어옴 | 축 군이 원국에 드러난 글자 없음 + 어느 층에든 들어옴 |
  | 다리 | 위 조건에 더해 렌즈가 정한 다른 군이 원국에 많음(자리·자격: 관성 많음 + 인성 들어옴 / 사업: 비겁 많음 + 식상 들어옴) — '없던 것이 들어옴' 문구를 대신한다 |
  | 대운에 놓인 10년 | 관할 대운에 축 글자 |
  | 줄이 함께 움직임 | 원국에 이어지는 구조 성립 + 세운·월운에 첫 축 군. 축 군이 많으면 '길면 무겁다'를 덧붙인다 |
  | 조언 | 세운·월운에 축 군이 든 군마다 한 문장 |
  | 대운 교체 전후 | 질문 기간이 교운 앞뒤 1년에 걸림(자리·자격 렌즈) |
  | 다음에 드는 해 | 질문 기간의 세운에 들지 않은 축 군(자리·자격 렌즈) |

- 사용 규칙(블록 끝 고정 문장): 표기된 층·글자만 쓴다 / 실리지 않은 달을 두고 '글자가 없다'고 말하지 않는다 / 유불리는 괄호의 역할과 사건 후보를 따른다 / 합격·성사·당락·시기를 확정하지 않는다 / '이 기간에는 ○○ 글자가 없다'는 선언을 쓰지 않는다 / 1~3문장, 가능성 어미.
- 층 줄 상한: 대운 2·세운 6·월운 6. 넘으면 그 층은 통째로 싣지 않는다(일부만 실으면 실리지 않은 기간을 오독한다).
- 시주 미상이면 블록을 내지 않는다(미상 ≠ 없음).
- 플래그 `SAJU_AXIS_LENS_BLOCK_ENABLED`(기본 true — 문구·기능층은 노출해야 감수 가능).
- 합격 준비 성향 사전(`exam_stage_traits.json` 1.1.0)에 인성 다자 항목 추가(3항목).

## 5. 다른 주제로의 확장 검토

같은 형태(원국의 축 군 상태 × 운에서 온 글자 → 주제의 말)가 다른 질문 유형에 이미 있는지를 실제 채팅 입력(데굴님 명식, 10개 질문, LLM 미호출)으로 확인했다.

| 주제 | 같은 형태가 이미 있는가 | 결정 |
|---|---|---|
| 재물 | 있음 — 재물 강의층(식상·재성 보완, 그릇 × 유입, 재성 대운 × 원국 식상, 재성 × 겁재) | 원국 × 운 문구는 추가하지 않는다. **재성의 천간/지지 양상만** 렌즈로 추가 |
| 창업·사업 | 없음 — 사업 토픽 신호(M08)뿐 | **사업 렌즈 추가**(재성·식상 두 축, 비겁 과다 + 식상 = 통관 다리) |
| 연애·결혼 | 있음 — 배우자성 블록, 배우자성 대운 라벨, 결혼 2축 계약, 이별운 운 문구 | 추가하지 않는다 |
| 이직 | 있음 — 직장 운 결(원국 천간 × 운 글자), 진입 시기 두 칸, 재직 기간 줄 | 추가하지 않는다 |
| 문서·계약(매매) | 일부 — 문서운 주의점·대비 블록, 물상 어휘 | 추가하지 않는다 — 인성·재성은 상생이 아니라 재극인 관계라 같은 틀로 옮길 통설 근거가 약하다 |
| 출산·자녀 | 없음 | **자녀 렌즈 추가**(성별 분기 — 여성 식상·남성 관성). 처음에는 민감 영역으로 보아 뺐으나 데굴님 정정("가능성 여부를 궁금해하는 부분이라 민감영역은 아니야")으로 넣었다 |
| 이사 | 있음 — 이사 이유·집 성격 십성 분류(천간 = 명분/지지 = 현장) | 추가하지 않는다 |
| 건강·구설 | 형태가 맞지 않음(위험 엔진·관계 층 관할) | 추가하지 않는다 |

- 자녀 렌즈는 자녀성 하나만 본다(없던 것이 들어옴·대운 10년·천간/지지 양상·조언). 자녀성은 다른 뜻(여성 식상 = 표현·활동, 남성 관성 = 직장·직책)도 함께 가지므로 머리말에 "자녀 얘기로만 좁혀 읽지 않는다"를 넣었고, '다음에 드는 해' 줄은 싣지 않는다. 성별 미상이면 렌즈가 없다. 사전 린트가 임신·출산 확정 어휘와 난임·불임을 막는다.
- 사업 렌즈와 재물 렌즈의 문구는 영상에 직접 문장이 없다. 영상의 틀을 통설(식상생재, 비겁 → 식상 → 재성 통관, 천간 = 드러남·지지 = 실속)에 옮긴 초안이며 사전 `basis` 에 그렇게 적었다. 실답 감수 대상이다.
- 렌즈 선택: 사건 키가 있으면 사건 표만 본다(합격·진학, 취업, 승진 → 자리·자격 / 사업 시작·확장 → 사업 / 재물 변화 → 재물 / 출산·자녀 → 자녀). 사건 키가 없으면 도메인(학업 → 자리·자격, 재물 → 재물). 공모·지원사업처럼 심사로 뽑히는 선발 질문은 자리·자격 렌즈를 쓰고, 추첨·배정형(군 입대·청약·기숙사·티켓팅)은 쓰지 않는다.

## 7. 남은 것

- 문구 실답 감수(자리·자격 14문장, 사업 13문장, 재물 2문장, 자녀 10문장, 준비 성향 인성 1문장).
- '다음에 드는 해' 줄이 답에서 "합격운이 오는 해"로 읽히는지 실답 확인.
- 출산 질문에서 자녀성이 질문 기간에 들지 않으면 자녀 렌즈 블록이 비어 있다 — '다음에 드는 해'를 자녀 렌즈에도 실을지는 결정 대기(나이와 무관하게 12년 뒤까지 해를 나열하게 된다).
- 승진 표지는 승진 이력(확정 달)이 쌓이면 §8 표를 다시 잰다.
- 합격 통지 달 표본이 쌓이면(대상 10명·30건 이상) 시기 규칙 재측정 — `EXTERNAL_TEXT_GAP_EXAM_LUCK_POST.md` §4의 조건 그대로.

## 8. 승진을 합격 기류 표지 대상에 (2026-11-20 데굴님 결정)

- 변경: `event_engine/exam_outcome_patterns.json` 의 `target_events` 에 `promotion` 추가. 승진 후보에도 같은 십성 패턴(관인상생·살인상생 등)의 합이 양수이면 '합격 기류 있음' 표지와 결과 유불리(favorability) 가산이 붙는다. 사건 형성도(점수)·순위·사건 종류는 바뀌지 않는다.
- 읽는 법 규칙(`EXAM_CURRENT_RULE`)에 한 문장 추가: 승진·인정 후보에 붙은 표지는 "승진 심사를 통과하는 쪽의 기류"로 옮겨 말하고 승진을 확정하지 않는다.
- 측정(원장 연 단위, 현행 규칙 그대로): 승진 이력 대상 12명·32칸.

  | 결과 | 칸 | 표지가 붙은 칸 |
  |---|---|---|
  | 승진 확정 | 1 | 1 |
  | 승진 없었음 | 31 | 8 (26%) |

- 읽기: 확정 1칸으로는 변별력을 말할 수 없다. '없었음' 31칸 가운데 26%에 표지가 붙으므로, 표지는 "그 해에 승진한다"가 아니라 "결과 쪽이 유리하게 읽히는 기류"까지만 뜻한다. 표지 대상 확대는 데굴님 결정으로 넣었고, 승진 확정 달이 쌓이면 같은 표를 다시 잰다.

### 8-1. 데굴님 명식의 승진 시기 대조 (2026-11-20, 데굴님 "입력보다는 시기만 맞춰봐")
