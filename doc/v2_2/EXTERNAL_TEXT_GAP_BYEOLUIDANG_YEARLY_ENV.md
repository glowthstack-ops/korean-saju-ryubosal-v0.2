## 3. 제안 — 우선순위와 범위 (2026-10-25 승인·구현 완료 — §2-6 참조)

### P0-1. 결함 수정: 계층 블록 천간 참여자 궁위 라벨
- 현상: `LAYER_KO[NATAL_MONTH]="원국 월지"`가 간·지 구분 없이 쓰여 丙壬沖이 "세운 丙 + 원국 **월지** 壬"로 LLM에 전달된다. LLM이 壬을 지지로 오인해 "월지 임수" 같은 오기를 낼 수 있는 입력 계약 결함.
- 수정안: `_who`(luck_hierarchy_render L29-31)에서 참여 글자가 천간이면 "원국 월간 壬", 지지면 "원국 월지 寅". 상수 테이블을 `(layer, is_stem)` 2키로 확장하거나 `_who`에서 접미만 치환. 반례 테스트(천간충 1건·지지충 1건) 추가.
- 영향: 서술 입력 라벨만 변경, 점수 불변. 기존 테스트에 "원국 월지" 리터럴 기대가 있으면 함께 수정.

### P0-2. 세운 환경 블록 `[세운 환경 — 월주 상대 기운]` (서술 전용, 학파 라벨)
- 계산(전부 기존 순수 함수·테이블 재사용, 신규 명리 규칙 없음):
  1. 월간 기준: 세운 천간 십성, 세운 지지 본기 십성, 세운 지지 12운성(`twelve_unseong(월간, 세운지지)`)
  2. 세운 천간 기준: 월간 십성, 월지 본기 십성, 월지 12운성(`twelve_unseong(세운천간, 월지)`)
  3. 세운 지지 ↔ 월지 관계(기존 `_relations_to_chart` 결과에서 월지 참여분만 필터)
  4. 세운 천간 ↔ 월간 합·충(기존 `interactions._pair_hits` stem 결과에서 NATAL_MONTH 참여분)
  5. 통근 비교: 세운 천간이 {월지, 세운 지지} 지장간에 뿌리 있는지 / 월간이 같은 두 지지에 뿌리 있는지 (지장간 테이블)
- 렌더: 머리말 `[월주 상대 관점 — 시절이 만드는 환경 (학파 서술: '월주와 세운의 상대 기운으로 보면 ~'로 쓸 것, 일간 기준 용신 판정과 합산·상쇄 금지·단정 금지)]` — `career_field._render_ganji_school`(L670-693)과 같은 규약. 라벨 명칭은 데굴님 결정("별의당 관점" / "월주 상대 관점").
- 사전: `yearly_environment.json`(신규, 소형) — ①십성 10종 × "환경 어휘"(예: 편재 = 큰 무대·활동 영역·기회 확장, 편관 = 관문·시험대·책임 요구) ②12운성 12종 × "환경 상태 어휘"(예: 胎 = 가능성이 품어진 상태, 長生 = 생조·시작의 힘) ③합성 지시(①+②+관계+통근 → "시절이 나에게 주는 환경 한 문장"). 기존 `ten_gods_text.incoming`은 '나에게 유입' 1인칭이라 월간 참조로 재사용하면 주어가 어긋난다 → 별도 사전이 필요. **어휘 20여 건은 데굴님 감수 대상.**
- 노출: 채팅 "해당 연 총운"(`_build_period_fortune` yearly 분기, `세운:` 줄 다음) + 리포트 F-11·Y-04 `luck_block` 뒤. 월운·일운에는 적용하지 않음(강의 범위 = 세운). 대운에 적용할지는 별도 결정.
- 금지: 환경 블록은 점수·후보 선별·역할 판정에 영향 없음(inert). 길흉은 기존 용희기신 축이 소유.

### P1-1. 태도 합성 지시문
- `_YEARLY_INSTRUCTION`에 한 줄 추가: "환경 블록이 있으면 ①시절이 만드는 환경 한 문장 → ②일간 기준 십성·12운성으로 명주가 취할 태도 한 문장 → ③둘을 합쳐 한 해 주제. 태도는 행동 권고가 아니라 '이 환경에서 발휘되기 쉬운 결'로 쓸 것." 결론 먼저 원칙(채팅 답변 계약)과 충돌하지 않게 첫 문단 3진 판정 뒤에 배치.
- 리포트 F-11·Y-04 `_SECTION_GUIDES`에 동일 문구.

### P1-2. 리포트 F-11·Y-04 패리티
- `build_luck_grounding` 호출을 추가해 12운성·관계 의미·신살·공망 줄을 채팅과 동일하게 제공. 계층 블록 포함 여부는 토큰 예산(섹션 상한 20k) 확인 후 결정.

### P2-1. 겁재 어휘 보강
- `ten_gods_text` 겁재 `incoming`·`asYongsin`에 "존재감 확립·동료와 함께 영역을 넓히는 결" 1구절. 비견은 `asYongsin`에 이미 연대 어휘가 있어 유지.

### P2-2. 12운성 어휘 보강(2건)
- 목욕 `incoming`에 "호기심·의외성" 1구절, 건록 `incoming`에 "존재감 확립" 1구절. 사는 변경 없음.

### 확인 필요(코드 변경 전 런타임 확인)
- "내년 총운" 채팅에서 `era_energy_lines(result, today.year)`가 올해 시대 기운을 붙이는지 실답으로 확인. 붙인다면 `_period_fortune_type`이 확정한 연도를 넘기도록 수정(P0-1과 같은 소형 수정).
