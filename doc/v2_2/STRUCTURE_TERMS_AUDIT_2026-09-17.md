## 2. 미적용·부분 항목 풀이용 초안 (structure_patterns.v1 형식)

표기 규약(기존 사전과 동일): `structure`(`->` 상생, `X` 극, `+` 병존), `polarity_mode`(favorable / unfavorable / depends_on_yonggi_and_control / context_only),
`llm_tag` 120자 이내, 길흉·사건 확정 금지(절대원칙 3·4). 감지 조건은 **기존 엔진 신호만** 사용하며, 새 명리 규칙이 필요한 항목은 등급 **B**로 표시해 사용자 결정을 받는다.

등급: **A** = 기존 신호 조합으로 즉시 감지 가능 / **B** = 임계값·규칙 확정 필요 / **C** = 배선 제외 권고(설명 태그도 금지) / **alias** = 기존 pattern에 동의어만 추가.
