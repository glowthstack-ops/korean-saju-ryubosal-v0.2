# 외부 강의 대조 — 「남자와 여자는 어떻게 다른가(천간·지지, 음양)」 vs 류보살 v2 엔진 (2026-10-29)

> 같은 강사의 이직·이별운 강의(`EXTERNAL_TEXT_GAP_CAREER_EXIT_LECTURE.md`·`EXTERNAL_TEXT_GAP_LOVE_SEPARATION.md`)와 짝. 강의는 참고 문헌이며, 기존 데굴님 결정과 충돌하면 절충하지 않고 묻는다.

## 1. 강의 요지

- 음양 비유: 천간=하늘·양·남자, 지지=땅·음·여자.
- 천간은 형체 없는 순수한 기운(생각), 지지는 그 기운이 형상화된 것(행동). 지지는 여러 천간을 품는다(강의 예: 寅 = 甲 50·戊 25·丙 25 — 엔진 값은 甲 0.60·戊 0.20·丙 0.20).
- 그래서 여자는 남자보다 현실적·합리적이고 남자는 뜬구름을 잡는다는 성별 일반화, 강사 개인 견해로 여성이 조금 더 우월하다.
- 결론: 하늘과 땅은 끝내 서로를 다 이해하지 못한다.

## 2. 대조

| 강의 | 엔진(2026-10-29) | 판정 |
|---|---|---|
| 천간=생각·지지=행동 | 행동 패턴 3층 규칙(2026-09-06 데굴님 승인)이 '천간=마음, 지지=행동' 고정 등식을 금지. 직업 사전 judgment_factors avoid 도 같은 금지. 직업 강의 대조(2026-10-16)에서 '참고만'. | 충돌 → 결정 3 |
| 여자=합리적·남자=뜬구름 | 엔진의 성별 차이는 명리 규칙에만 있다(배우자성 남=재성·여=관성, 대운 순역, 궁합 성별 문구). 성별만으로 성향을 단정하는 규칙 없음, 낙인 금지 정책. | 불채택 → 결정 1 |
| 寅 지장간 50·25·25 | 만세력 상수 甲 0.60·戊 0.20·丙 0.20 | 엔진 값 유지(재구현 금지) |
| 끝내 다 이해하지 못함 — 다름 인정 | 이별운 강의 마무리와 같은 결. 관계 관점 문구 없음. | 채택 → 결정 2 |

## 3. 데굴님 결정 (2026-10-29)

1. 성별 성향 일반화는 명식 근거가 아니므로 싣지 않는다 — "의견에 동의해".
2. A안 — 강의 결론(다름의 인정)만 관계·궁합 관점 문구로 — "권장대로 가자".
3. '천간=생각·지지=행동'은 고정 등식 금지를 유지하고, 개념 설명용 비유는 **해설 한정 예외** — "비유 해설 한정 예외로 두는 게 나을 것 같아".

## 4. 구현

- `structural_context.RELATIONSHIP_DIFFERENCE_PERSPECTIVE` — 다름의 인정 + 성별 일반화 금지 가드('여자는 현실적·합리적', '남자는 생각만 앞선다' 류 금지, 차이는 명식 근거로만). 답 마무리 위치는 지정하지 않는다(규칙 8 소유). 채팅 연애 관계 블록(`_structural_context`)과 궁합 블록(`_compat_prompt_block`)에 부착.
- `BEHAVIOR_PATTERN_DIRECTIVE` — 고정 등식 금지 유지 + "개념 자체를 설명할 때 비유를 해설로 쓰는 것은 허용, 그 비유로 이 명식의 성향·행동을 판정하지 않는다".
- `terminology.json` 천간·지지 정의에 비유 해설 + "개념 비유일 뿐 성향 판정 기준은 아니에요". `career_fields.json` avoid 에 예외 범위 명시.
