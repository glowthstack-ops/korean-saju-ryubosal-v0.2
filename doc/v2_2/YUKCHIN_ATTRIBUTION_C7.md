# C7 — 육친 귀속 대조표와 결정 요청 (2026-10-08)

> 범위: 사례집(85사례)의 육친 해설 ↔ 현 엔진·문서의 육친 규칙 ↔ 고전 통설. **문서 대조 단계 — 구현·런타임 테스트 없음**(데굴님 지시).
> 구현은 §5 결정 후. 인벤토리 원본: `cases/comparison_casebook/c7_yukchin_inventory.md`(코드·문서 행 번호 전수).

## 0. 요약

- 사례집 24사례에 육친 언급, 그중 귀속 규칙을 명시한 해설 4건(028·052·053·067)은 전부 고전 통설과 정합한다(§4 I-5).
- 현 엔진은 **배우자 축만 성별 분기**(남명 재성·여명 관성)하고, 부모는 인성 통칭(M04), 자녀는 식상 고정(M05)이다. 부친=편재, 남명 자녀=관살 같은
  고전 규칙이 **점수 경로에 없다**(§4 M-1·M-2). 문서(docs/09·10)와 코드의 의미 불일치 2건(M-3·M-4).
- 특정 글자 귀속(戌중 辛=남편), 2차 육친 인물(시어머니·장인), 활법(活法) 대체 규칙, 육친 글자 운으로 인물 사건 추론은 **미지원**이며,
  근거·단정 위험상 미구현 유지를 권고한다(§4 U-1~U-6).
- 결정 요청 6건(§5). 권고 핵심: D1 M04 부친 축 편재 추가, D2 M05 남명 자녀 서술 분기(이벤트 불변), D3 F-17b 문구 정정, D4 docs/09 궁위 규격 정정.

고전 원문(A) 발췌:
- 妻: "大率依財看妻，如喜神即是財神，其妻美而且富貴"
- 子(남명): "大率依官星看子，如喜神即官星，其子賢俊"
- 父母: "子平之法，**以財為父，以印為母**，然看歲月為緊要… 歲月之氣，斲喪於時干者，先剋父，歲月之氣，斲喪於時支者，先剋母"
- 兄弟: "劫財，比肩，陽刃，皆兄弟"
- 女命 夫: "局中官星明順，夫貴而吉… 若官星太旺，以傷為夫，官星太微，以財為夫，比肩旺而無官，以食傷為夫，傷官旺而無財官，印綬為夫"
- 女命 子: "局中食神清顯，子貴而清… 若傷官太旺，以印為子，食神無氣，以比肩為子，印旺而無傷官者以財為子"
