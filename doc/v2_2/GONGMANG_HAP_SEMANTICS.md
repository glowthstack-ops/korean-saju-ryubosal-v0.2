# 공망 × 합 의미론 (SSOT)

> 2026-08-21 데굴님 확정. 발단: 己亥일주(공망 辰巳) 명식의 2026-08 丙申월 풀이가
> "申金이 공망과 겹치면서 지연·공허"로 서술된 사례 — 申은 공망 글자가 아니라
> 공망지 巳의 육합 파트너였고, 엔진이 '해소(합)' 판정을 지연 게이트(VOID_delay)로
> 뒤집어 전달한 결함이 원인이었다.

## 1. 확정 원칙

**공망 = 대상의 작용 억제/허화. 합 = 그 대상을 연결·활성화.**
→ 합이 오면 공망의 억제가 줄어들면서 **억제되어 있던 대상(지지·십성·궁위·구조)의
본래 작용이 현실화**될 수 있다.

고전 근거: 《삼명통회》 공망론 — 길신이 공망이면 합을 반기고 흉신이 공망이면 합을
꺼린다. 이유는 **"合則不能空"**(합하면 더 이상 비어 있을 수 없다). 즉 합 자체가
길흉이 아니라, 합이 공망의 차단막을 약화시킨 뒤 **안에 있던 것이 무엇이냐**가 결정한다.

| 질문 | 판정 |
|---|---|
| 합이 공망을 해소하는가? | 그렇다 — 억제력을 약화(해공 방향). 단 충(강, ~80%)보다 약한 부드러운 해공(~40%) |
| 합이 사건을 발동시키는가? | 그렇다 — 공망지를 관계망으로 끌어내 사건 활성화 계기가 된다 |
| 합이 '공망의 흉함'을 발동시키는가? | **아니다 — 이 표현은 부정확하다(서술 금지)** |
| 무엇이 발동하는가? | 공망 때문에 약화되어 있던 지지·십성·궁위·구조의 본래 작용 |
| 그 결과가 길한가 흉한가? | 용희기구한·원국 구조·합의 상대·운 품질로 **별도 판정** |

## 2. 2축 분리 (모순 아님)

- **VOID_STATE(공망 효력)**: `FULL_VOID → PARTIAL_VOID → RELEASED`
- **ACTIVATION(사건 활성도)**: `DORMANT → CONTACTED → ACTIVATED`

육합 발생 시: `FULL_VOID+DORMANT → PARTIAL_VOID/RELEASED + ACTIVATED`.
"공망은 해소되는데 사건은 발동한다"가 정상 서술이다.

## 3. 해공 강도 계층 (boolean 금지)

| 자극 | 해공/활성 강도 |
|---|---|
| 동일 공망 글자의 운 출현(전실·填實) | 가장 명확한 실체화 |
| 완전한 육합 | 강한 연결·해공 |
| 완성된 삼합국 | 강한 구조적 활성화 |
| 반합·부분 삼합 | 부분 활성화 |
| 암합 | 약한 활성화 |
| 합 상대까지 공망 | 해공력 크게 감산 |
| 합화 불성립 | 합의 접촉은 인정, 합화 결과 오행까지는 불인정 |
| (참고) 방합 | 해공 능력 거의 없음 |

**해공 강도 ≠ 사건 활성도** — 약하게 해공되어도 특정 궁위·십성에 운이 직접
접촉했다면 사건 후보 생성에는 의미가 있을 수 있다.

## 4. 엔진 최종 규칙

> 합은 공망을 단순 제거하는 규칙이 아니라, **공망된 지지의 suppression을 완화하고
> activation을 증가시키는 관계 신호**다. 합으로 살아난 대상의 길흉·사건 의미는
> 그 지지의 십성·궁위·용희기구한·구조 신호로 별도 판정한다.

이로써 "공망 합발 후 사건은 났는데 결과가 나빴던" 사례도 설명되며,
"해공됐으니 길하다"는 잘못된 등식을 피한다.

### 7-1. 고전 근거(웹 확인)와 현대 통설

- 《삼명통회》 권3 〈논공망〉 원문: 흉신 자리는 "有空亡不宜見合, 合則不能空矣", 길신(祿馬財官) 자리는
  "有空亡却喜見合, 合則不能空矣" — 합이 공망을 풀어 안에 있던 것을 살린다는 §1 원칙의 원문 근거.
  같은 장: "若無沖無合無刑, 謂眞空亡" — **충·합·형** 셋이 모두 없을 때만 진공망. 따라서 해공 자극에
  **형을 포함**한다(§7-3 자극 종류). 출처: 識典古籍 SK1610 論空亡, zggdwx.com/sanming/76.
- 통설(여러 명리 해설, 확정 출처 없음): "旺不爲空 — 왕상의 공망은 전실·충·합·삼회로 풀리고, 휴수의 공망은
  풀기 어렵다" → 강도(자왕) 등급의 근거(가설). 사대공망=납음 결손(甲子·甲午旬 水 / 甲寅·甲申旬 金),
  절로공망=시간 壬·癸, 호환공망=연↔일·일↔시 상호 旬공, 진공/반공의 음양 기준은 출처마다 달라 **보류**.
- **현대 풀이 통설(데굴님 명시, 2026-10-23)**: 대운에 오는 공망(대운 지지가 공망 글자)은 영향을 무시하고,
  세운 공망은 어느 정도 인정한다. 월운·일운은 세운과 같은 취급(기존 유지, P4 측정 대상).
