# 지장간 비중 — 적용 기준 (v2.1)

## 핵심 원칙
오행/십성 **비중**은 두 가지를 곱해서 구한다:
1. **자리별(위치) 가중치** — 분포 계층 `BRANCH_POS_WEIGHT` = 年12·月28·日24·時16 (천간은 STEM_POS_WEIGHT 年8·月12·日0·時10). 月支·日支를 무겁게 본다.
2. **지지 내 본/중/여 분배 비율** — 아래 표(사용자 지정). 정기(본기)>중기>여기.

> 월률분야 일수(7:7:16 등)는 **비중 산식에 사용하지 않는다**(과거 시도 철회). 일수는 사령(월령용사)
> 표시 참고로만 의미가 있고, 비중 계산의 본/중/여 분배는 아래 고정 비율을 쓴다.

## 적용 본/중/여 분배 비율 (budget, 합=1.0)

| 지지 | 여기 | 중기 | 정기 | 비율 |
|---|---|---|---|---|
| 子 | 壬 | — | 癸 | 0.30 / — / 0.70 |
| 丑 | 癸 | 辛 | 己 | 0.20 / 0.20 / 0.60 |
| 寅 | 戊 | 丙 | 甲 | 0.20 / 0.20 / 0.60 |
| 卯 | 甲 | — | 乙 | 0.30 / — / 0.70 |
| 辰 | 乙 | 癸 | 戊 | 0.20 / 0.20 / 0.60 |
| 巳 | 戊 | 庚 | 丙 | 0.20 / 0.20 / 0.60 |
| 午 | 丙 | 己 | 丁 | 0.30 / 0.20 / 0.50 |
| 未 | 丁 | 乙 | 己 | 0.20 / 0.20 / 0.60 |
| 申 | 戊 | 壬 | 庚 | 0.20 / 0.20 / 0.60 |
| 酉 | 庚 | — | 辛 | 0.30 / — / 0.70 |
| 戌 | 辛 | 丁 | 戊 | 0.20 / 0.20 / 0.60 |
| 亥 | 戊 | 甲 | 壬 | 0.20 / 0.20 / 0.60 |

- 3지장간: 여0.20·중0.20·정0.60
- 왕지 子卯酉: 여0.30·정0.70
- 午(예외): 丙0.30·己0.20·丁0.50
- 亥 戊 인정(戊 여기 0.20)

## effective(비중) 1글자 산식
```
기여 = BRANCH_POS_WEIGHT[자리] × (위 본/중/여 비율) × 월령보정 × 투간 × 공망
```
예) 月支 亥(자리 28): 戊 28×0.20=5.6 · 甲 28×0.20=5.6 · 壬 28×0.60=16.8(월령본기 ×1.3)

## 표시(visible)와의 분리
사용자 화면 기본 '표면 분포'는 천간·지지 표면 글자 **단순 카운트**(자리별 가중치·지장간 비율 미적용).
effective(자리별+본중여)는 '실세력'으로 병표한다.
